자유 프로젝트(7장)를 위해 확장 부품 파우치가 준비되어 있어요. 여기 있는 부품은 전부 피코 2 WH + 그로브 쉴드의 번호 핀 소켓에 암수 점퍼 케이블로 바로 연결할 수 있는 것만 골랐습니다. 부품마다 배선표 → AI 프롬프트 → 확인용 코드 순서로 쓰면 돼요.

🎯 이 페이지 사용법 — 3단계
  • ① 배선표대로 연결하고 (쉴드 전원 스위치는 항상 3.3V!)
  • ② 확인용 코드를 복사해 올려서 부품이 살아 있는지 먼저 확인한 다음

💡 왜 이 부품들만 골랐나요?

키트에는 부품이 60가지도 넘지만, 우리 방식(그로브 쉴드 + 점퍼)과 맞는 건 "전원 2줄 + 신호 1~2줄이면 끝나는 완성형 모듈"이에요. 저항을 조합해 회로를 설계해야 하는 부품(낱개 LED·트랜지스터·7세그먼트 등)은 이번 프로젝트 범위 밖이라 뺐습니다. 자세한 이유는 맨 아래 "키트에 있지만 쓰지 않는 부품"을 보세요.

🔌 먼저 읽기 — 연결 규칙 & 핀 배정 지도

① 핀 소켓 두 줄이 정답지
쉴드에는 피코의 모든 핀이 GP 번호 그대로 암핀 소켓 두 줄로 나와 있어요. USB를 위로 두면 왼쪽 줄(GP0~GP15 쪽), 오른쪽 줄(GP16~GP28·3V3·GND 쪽). 키트 부품은 이 핀 소켓에 암수 점퍼(수 핀 쪽 → 쉴드 구멍, 암 구멍 쪽 → 부품 핀)로 연결합니다. 위치가 헷갈리면 쉴드에 인쇄된 GP 번호가 정답!
② 점퍼 색 약속
노랑 = 신호  흰색 = 둘째 신호
빨강 = 3V3(전원)  검정 = GND
전기적으로는 아무 색이나 동작하지만, 약속을 지키면 배선 점검이 5초로 끝나요.
③ 전원은 3V3만 — VBUS 금지
빨강 점퍼는 언제나 오른쪽 줄 위쪽의 3V3 구멍에. 그보다 더 위에 있는 VBUS는 5V라서 절대 헷갈리면 안 돼요! 쉴드의 전원 스위치도 항상 3.3V 고정. 5V가 꼭 필요하면 선생님과 함께!
💡 그로브 소켓은 딱 두 부품만 씁니다
그로브 케이블용 소켓은 교재 기본 부품인 WS2813 LED 바(D16 소켓)와 MQ-2 가스센서(A0 소켓 + 그로브→암점퍼 변환 케이블) 전용이에요 — 기본 배선 그대로 두면 됩니다. 이 페이지의 키트 부품을 그로브 소켓에 꽂으려고 애쓰지 마세요!

핀 배정 지도 — 교재에서 이미 쓰는 핀(LED·가스센서)은 그대로 두고, 남는 핀에 확장 부품을 배치합니다. 같은 핀에 배정된 부품끼리는 동시에 쓸 수 없으니 프로젝트 계획 때 확인하세요.

⚙️부품 1 · 서보 모터 (SG90)난이도 ★☆☆핀 소켓 GP18

지금까지는 데이터를 빛(LED)으로만 표현했죠. 서보는 0~180도로 정확히 움직이는 작은 모터예요. 데이터를 바늘이 가리키는 아날로그 게이지로 바꿀 수 있는, 이 파우치에서 가장 추천하는 부품입니다.

부품 핀 (서보 선 색)쉴드의 어느 구멍에?점퍼 색 (추천)
주황 (신호)핀 소켓 GP18 (오른쪽 줄 아래쪽)노랑
빨강 (전원)핀 소켓 3V3 (오른쪽 줄 위쪽 · VBUS 5V 금지!)빨강
갈색 (접지)핀 소켓 GND — GP18 바로 아래 칸검정

서보 케이블 끝은 암(구멍) 커넥터예요. 커넥터 구멍과 쉴드 핀 소켓 양쪽에 다 꽂히도록 수수(양쪽 핀) 점퍼 3개를 쓰세요.

확인용 코드 — 서보가 0° → 90° → 180°로 움직이면 성공MicroPython
# SG90 서보 — 각도 제어 (핀 소켓 GP18)
from machine import Pin, PWM
import time

servo = PWM(Pin(18))
servo.freq(50)                        # 서보는 50Hz(20ms 주기) 신호를 사용해요

def angle(deg):
    # 0도 = 0.5ms 펄스, 180도 = 2.5ms 펄스 → duty_u16(0~65535)로 환산
    us = 500 + int(deg) * 2000 // 180
    servo.duty_u16(us * 65535 // 20000)

angle(0);   time.sleep(1)
angle(90);  time.sleep(1)
angle(180); time.sleep(1)
angle(90)                             # 가운데로 복귀
🤖바이브코딩 프롬프트 — 강수확률 바늘 게이지
[맥락] 내 피코는 5장 코드로 Open-Meteo에서 오늘 강수확률(%)을 받아오고 있어. [하드웨어] SG90 서보가 GP18에 연결돼 있어 (50Hz PWM, 0도=0.5ms·180도=2.5ms 펄스). 와이파이는 wifi_config.py에 저장된 WIFI_SSID, WIFI_PASSWORD를 from wifi_config import WIFI_SSID, WIFI_PASSWORD로 불러와서 연결해. 코드에 이름/비번을 직접 쓰거나 새 변수로 재정의하지 마. [작업] 오늘 강수확률 0~100%를 서보 각도 0~180도로 바꿔서, 종이 눈금판 위에서 바늘이 오늘 비 올 확률을 가리키는 아날로그 날씨 게이지를 만들어 줘. 좌표는 5장처럼 코드 상단 LAT, LON 변수(기본 37.5665, 126.9780)로 두고 우리 학교 좌표로 바꿀 수 있게 해 줘. [제약] 데이터 갱신은 30분마다, 외부 라이브러리는 쓰지 말고, 갱신할 때 바늘이 부드럽게(1도씩) 움직이게. [출력] 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.
💡 꾸미기 팁
두꺼운 종이에 부채꼴 눈금판(☀️ 0% ~ ☔ 100%)을 그리고 서보 날개에 바늘을 붙이면 진짜 '아날로그 날씨 시계'가 됩니다. 3.3V에서는 힘이 살짝 약하지만 종이 바늘을 돌리기엔 충분해요.
🌡️부품 2 · DHT11 온습도 센서난이도 ★☆☆핀 소켓 GP20

온도와 습도를 한 번에 재는 파란 그물 모양 센서. 6장 구글 시트 기록에 온도·습도 열을 추가하면, 가스 농도와 온습도의 관계까지 탐구할 수 있어요.

부품 핀쉴드의 어느 구멍에?점퍼 색 (추천)
DATA (신호)핀 소켓 GP20 (오른쪽 줄 아래쪽)노랑
VCC핀 소켓 3V3 (오른쪽 줄 위쪽 · VBUS 5V 금지!)빨강

확인용 코드 — 2초마다 온도·습도가 찍히면 성공MicroPython
# DHT11 온습도 — 2초마다 읽기 (핀 소켓 GP20)
import dht, time
from machine import Pin

sensor = dht.DHT11(Pin(20))

while True:
    time.sleep(2)                     # DHT11은 최소 2초 간격으로만 읽을 수 있어요
    try:
        sensor.measure()
        print("온도:", sensor.temperature(), "°C   습도:", sensor.humidity(), "%")
    except OSError:
        print("읽기 실패 — 신호선이 GP20(노랑)에 잘 꽂혔는지 확인!")

📏부품 3 · 초음파 거리 센서 (HC-SR04)난이도 ★★☆핀 소켓 GP18·GP19

눈처럼 생긴 두 개의 원통에서 초음파를 쏘고(TRIG) 메아리를 받아(ECHO) 거리를 잽니다. 박쥐와 같은 원리! 신호가 2개지만 GP18·GP19가 핀 소켓에서 아래위로 나란한 칸이라 배선은 어렵지 않아요.

부품 핀쉴드의 어느 구멍에?점퍼 색 (추천)
TRIG (쏘기)핀 소켓 GP18 (오른쪽 줄 아래쪽)노랑
ECHO (받기)핀 소켓 GP19 — GP18 바로 위 칸흰색
VCC핀 소켓 3V3 (오른쪽 줄 위쪽 · VBUS 5V 금지!)빨강
GND핀 소켓 GND — GP18 바로 아래 칸검정
확인용 코드 — 손을 가까이/멀리 하면 숫자가 변하면 성공MicroPython
# 초음파 거리 측정 (핀 소켓 GP18=TRIG, GP19=ECHO)
from machine import Pin, time_pulse_us
import time

trig = Pin(18, Pin.OUT)
echo = Pin(19, Pin.IN)

def distance_cm():
    trig.value(0); time.sleep_us(2)
    trig.value(1); time.sleep_us(10)   # 10µs 동안 초음파 발사!
    trig.value(0)
    t = time_pulse_us(echo, 1, 30000)  # 메아리가 돌아온 시간(µs), 최대 30ms 대기
    if t < 0:
        return None                    # 시간 초과 = 측정 실패
    return t * 0.0343 / 2              # 소리 속도(343m/s)로 왕복→편도 거리 환산

while True:
    d = distance_cm()
    print("거리: %.1f cm" % d if d else "측정 실패 — 배선과 방향을 확인해 보세요")
    time.sleep(0.3)
🤖바이브코딩 프롬프트 — 거리 게이지 & 접근 경보
[맥락] 내 피코에서 초음파 센서로 거리를 재는 distance_cm() 함수가 돌아가고 있어. [하드웨어] 초음파 센서는 TRIG=GP18, ECHO=GP19. 열 칸 LED 바(WS2813)는 16번 핀이고 만들 때 timing=(280,515,515,745) 지정이 꼭 필요해. [작업] 거리 10~100cm를 LED 10칸 게이지로 표시해 줘 (가까울수록 많이 켜지고 초록→노랑→빨강으로). 20cm 안으로 들어오면 전체를 빨갛게 깜빡이는 '접근 경보'도 넣어 줘. [제약] 0.2초마다 측정, 측정 실패(None)일 때는 LED를 끄고 넘어가기, LED 밝기는 채널당 40 이하. [출력] 복사해서 바로 돌아가는 완결형 main.py 전체.
⚠️ 값이 이상하다면
HC-SR04는 원래 5V용이라, 3.3V에서는 측정 가능 거리가 짧아지거나 가끔 실패할 수 있어요. "측정 실패"가 계속 뜨면 센서를 벽처럼 평평한 곳을 향하게 해 보고, 그래도 안 되면 선생님과 함께 확인하세요.

돔 모양 흰 렌즈로 사람이나 동물의 움직임(적외선 변화)을 감지합니다. 복도 자동등, 교실 출입 카운터, 우리 반 보안 시스템의 핵심 부품.

부품 핀쉴드의 어느 구멍에?점퍼 색 (추천)
OUT (가운데)핀 소켓 GP20 (오른쪽 줄 아래쪽)노랑
VCC핀 소켓 3V3 (오른쪽 줄 위쪽 · VBUS 5V 금지!)빨강
GND핀 소켓 GND — GP20에서 두 칸 위검정
확인용 코드 — 손을 흔들면 "움직임 감지!"가 뜨면 성공MicroPython
# PIR 동작 감지 (핀 소켓 GP20)
from machine import Pin
import time

pir = Pin(20, Pin.IN)

print("센서 안정화 중... 30초만 가만히 기다려 주세요")
time.sleep(30)                        # PIR은 켜진 직후엔 오작동해요 — 워밍업 필수!
print("감시 시작 👀")

while True:
    if pir.value() == 1:
        print("🚨 움직임 감지!", time.ticks_ms() // 1000, "초")

# I2C LCD1602 — 글자 출력 (핀 소켓 GP4=SDA · GP5=SCL을 I2C로 사용)
# 외부 라이브러리 없이 동작하는 초간단 드라이버 포함!
from machine import I2C, Pin
import time

i2c = I2C(0, sda=Pin(4), scl=Pin(5), freq=100000)
devs = i2c.scan()
if not devs:
    raise RuntimeError("LCD 못 찾음 — SDA(GP4)/SCL(GP5) 배선을 확인하세요")
ADDR = 0x27 if 0x27 in devs else (0x3F if 0x3F in devs else devs[0])

# ---- LCD1602 미니 드라이버 (PCF8574 방식) ----
def _w4(d):                            # 4비트 + 백라이트 켠 채로 E펄스
    i2c.writeto(ADDR, bytes([d | 0x0C, d | 0x08]))
def _cmd(c):                           # 명령 보내기
    _w4(c & 0xF0); _w4((c << 4) & 0xF0); time.sleep_ms(2)
def _chr(c):                           # 글자 보내기 (RS=1)
    _w4((c & 0xF0) | 1); _w4(((c << 4) & 0xF0) | 1)
def lcd_init():
    time.sleep_ms(50)
    for c in (0x33, 0x32, 0x28, 0x0C, 0x06, 0x01):
        _cmd(c)
def lcd_print(text, line=0):           # line 0=윗줄, 1=아랫줄 (영문·숫자만!)
    _cmd(0x80 + (0x40 if line else 0))
    for ch in text[:16]:
        _chr(ord(ch))
# ---------------------------------------------

lcd_init()
lcd_print("Hello, Pico!")
lcd_print("Vibe Coding :)", 1)
