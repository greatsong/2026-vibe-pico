CHAPTER 07

자유 프로젝트

지금까지 배운 LED·센서·웹·날씨 API·시트 기록을 조합해, 나만의 작품을 바이브코딩으로 완성합니다.

🎯 이 장을 마치면
  • 여러 기능을 조합해 새 작품을 기획할 수 있다
  • AI에게 명확하게 설명하고, 받은 코드를 점검할 수 있다
💡 왜 배우나요?

도구는 다 익혔어요. 이제 ‘무엇을 만들까’가 남았습니다. 작은 아이디어 하나면 충분해요. 아래 아이디어와 프롬프트 틀을 출발점으로 삼아, 우리 교실·우리 집에 쓸모 있는 작품을 만들어 보세요.

아이디어 모음

🌧️ 우산 알리미
날씨 시계(5장)에서 오늘 강수확률이 60% 넘는 시간대가 있으면, 현관 LED를 파랑으로 깜빡여 ‘우산 챙겨!’
🌬️ 스마트 환기등
가스센서(3·4장) 값이 WARNING을 넘으면 LED를 노랑→빨강으로, 웹에 ‘환기하세요’ 알림.
📶 와이파이 약한 자리 찾기
RSSI 대시보드(1장)를 들고 다니며 집에서 신호가 약한 곳을 LED 게이지로 탐색.
🌡️ 오늘 날씨 무드등
강수확률 대신 기온을 받아(Open-Meteo) 더우면 빨강, 추우면 파랑으로 방 전체 분위기 표현.
🔭 과학 데이터 작품
부록 A 갤러리에서 API 하나 골라(지진·낮 길이·CO₂…) 값을 10칸 LED 게이지로. 각 페이지에 ‘AI에게 설명’ 프롬프트가 있어요.
📒 일주일 공기질 리포트
기록 노트(6장)를 일주일 돌려 요일별 패턴을 차트로 비교하고, 데이터를 근거로 ‘우리 반 환기 규칙’을 제안하는 탐구 보고서.

AI에게 잘 설명하는 틀

막연히 ‘만들어 줘’보다, ① 지금 상태 → ② 추가할 동작 → ③ 제약(핀·timing·갱신주기)을 함께 설명하면 훨씬 정확한 코드를 받습니다.

🤖AI에게 이렇게 설명하세요 — 틀 (복사해서 채우세요)
[맥락] 내 피코는 지금 ____ 를 하고 있어. (예: 오늘 강수확률을 열 칸 LED에 색으로 표시) [하드웨어] 열 칸짜리 LED 바(WS2813)는 16번 핀, 만들 때 타이밍 값 네 개(280, 515, 515, 745) 지정 필요 / 가스센서(MQ-2)는 아날로그 26번 핀 / 와이파이 정보는 설정 파일(wifi_config.py)에서 불러옴. [작업] 여기에 ____ 기능을 더해줘. (예: 강수확률이 60%를 넘으면 LED 깜빡이기) [제약] 외부 라이브러리는 최소로, 데이터 갱신은 ____초마다. [출력] 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘. 받은 코드에서 핀 번호와 타이밍 값이 내 것과 같은지 확인할게.
💡 점검 체크리스트
받은 코드를 올리기 전에: ① timing=(280,515,515,745) 있는지 ② 핀 번호(16 / 26)와 포트(D16 / A0) 맞는지 ③ 무한 반복 속 sleep으로 쉬어 주는지 ④ 와이파이/네트워크 요청이 과하지 않은지.
