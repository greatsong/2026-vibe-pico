# 📖 인쇄용 교재 (DOCX) — A5 판형 · 2쪽 모아찍기

웹 교재(`build_site.py`의 콘텐츠)를 **그대로 읽어** A5 판형 DOCX로 만듭니다.
A4 한 장에 **2쪽씩 모아찍으면 A5 실물 크기 그대로** 인쇄됩니다(축소 없음 = 글자 안 작아짐).

| 파일 | 내용 | 분량 |
|---|---|---|
| `피코_바이브코딩_교재_A5_학생용.docx` | 본문 0~7장 + 부록 A·C | 약 74쪽 |
| `피코_바이브코딩_교재_A5_강사용.docx` | 위 + **강사노트**(진행 멘트·발문·이론 심화·예상 오류) + **20시간 운영 계획** | 약 96쪽 |

## 다시 만들기

```bash
python3 print/export_content.py              # 웹 콘텐츠 → print/content.json
python3 print/export_content.py --teacher    # 강사노트 포함본
node print/build_docx.js                     # → 학생용 docx
node print/build_docx.js --teacher           # → 강사용 docx
```

`build_site.py`의 본문을 고친 뒤 위 4줄만 다시 돌리면 인쇄본도 최신이 됩니다.
(처음 한 번은 `cd print && npm install docx` 필요)

## 인쇄 방법 — A4에 2쪽 모아찍기

1. Word에서 DOCX를 열고 **파일 → 인쇄**
2. 용지: **A4** / 방향: 자동(가로로 배치됨)
3. **한 면에 여러 페이지 → 2페이지** 선택
   - macOS Word·미리보기: `레이아웃 → 페이지당 페이지 수: 2`
   - 한글(HWP)로 열었다면: `인쇄 → 모아 찍기 → 2쪽씩`
4. 양면 인쇄를 켜면 **A4 한 장 = 4쪽** — 74쪽 교재가 약 19장이 됩니다.
5. 중철제본(가운데 스테이플)을 하려면 Word의 **소책자(Booklet)** 레이아웃을 쓰세요.

> 📄 **표지·목차**: 목차 페이지 번호가 비어 보이면 목차를 클릭하고 **F9**(필드 업데이트)를 누르세요.
> 🔤 **폰트**: 본문은 맑은 고딕, 코드는 Consolas 기준입니다. 없는 환경에서는 자동 대체되며 레이아웃은 유지됩니다.

## 웹에만 있는 요소

인쇄본에서 아래 항목은 *"웹 교재에서 확인하세요"* 안내로 대체됩니다 — 종이로 옮길 수 없는 것들입니다.

- 하드웨어 배선 그림·인터랙티브 배선표(체크하며 따라가는 위젯)
- 6장의 **웹 앱 URL 붙여넣기 상자**(코드 자동 반영)
- ML 확장판의 흐름 애니메이션·모의 테스트
