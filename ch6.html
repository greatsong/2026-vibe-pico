CHAPTER 06

우리반 공기질 기록 노트 (센서 → 구글 시트)

피코가 잰 공기질을 구글 시트에 1분마다 자동 기록합니다. 밤새 쌓인 데이터를 아침에 열어 보면 — 우리가 없는 동안의 교실이 보여요.

🎯 이 장을 마치면
  • ‘실시간으로 보는 것’과 ‘기록으로 남기는 것’의 차이를 설명할 수 있다
  • Google Apps Script 웹앱을 만들고 ‘모든 사용자’로 배포할 수 있다
  • 피코에서 센서값을 HTTPS로 구글 시트에 자동 기록할 수 있다
  • 쌓인 데이터를 차트·조건부 서식으로 탐구하고 결론 한 줄을 쓸 수 있다
💡 왜 배우나요?

지난 장에서 피코는 인터넷에서 데이터를 받아 왔죠(Open-Meteo). 이번엔 방향을 뒤집어 보냅니다. 3·4장의 공기질은 화면을 보는 ‘그 순간’만 알 수 있었어요 — 그런데 어젯밤 우리 교실 공기는 어땠을까요? 아무도 모릅니다. 기록하지 않았으니까요. 이 장에서는 피코가 잰 값을 구글 시트에 1분마다 한 줄씩 자동으로 쌓습니다. 시트는 무료이고, Apps Script 웹앱을 거치면 피코가 로그인 없이 URL 하나로 기록할 수 있어요. 데이터가 시간과 만나면, 순간의 숫자가 이야기가 됩니다.

핵심 개념 — ‘보는 것’에서 ‘남기는 것’으로

로깅(logging)
측정값을 시각과 함께 차곡차곡 저장하는 것. 걸음 수 앱, 블랙박스, 관측소가 모두 로깅 장치예요.
실시간 vs 기록
실시간(3·4장)은 지금을 알려주고, 기록은 변화·패턴·비교를 알려줍니다. ‘언제 나빠지나’는 기록만이 답할 수 있어요.
웹 앱(Web App)
URL을 부르면 실행되는 작은 프로그램. 우리는 Apps Script로 ‘값을 받아 시트에 한 줄 쓰는’ 웹앱을 만듭니다.
이번 장의 방향
1·3장: 피코가 서버(브라우저가 가지러 옴) → 5장: 피코가 받아옴 → 이번 장: 피코가 보냄. 도구는 같고 방향만 반대예요.
🔑 왜 구글 시트에 ‘바로’ 못 쓰나요? — 우편함이 필요한 이유
구글 시트에 직접 쓰려면 구글 로그인(인증)이 필요한데, 작은 피코는 그 복잡한 절차를 감당하기 어려워요. 그래서 중간에 Apps Script 웹앱이라는 우편함을 세웁니다 — 웹앱은 내 계정 권한으로 시트에 쓸 수 있고, 피코는 우편함 주소(URL)만 알면 값을 던져 넣으면 돼요. ‘로그인은 웹앱이, 배달은 피코가’ — 이 분업이 이 장의 핵심 구조입니다.
🔬 더 알아보기 — 리다이렉트 — 구글이 ‘저쪽 창구로 가세요’ 하는 것
피코가 웹앱 주소로 요청을 보내면, 구글은 종종 302라는 답과 함께 ‘진짜 처리는 이 주소에서 해요’라고 다른 주소를 알려줍니다. 은행에서 번호표를 뽑았더니 “이 업무는 3번 창구로 가세요” 하는 것과 같아요. 브라우저는 이걸 자동으로 따라가지만, 우리가 직접 만드는 피코 코드는 Location(새 주소)을 읽어 한 번 더 요청해야 합니다. 아래 완성 코드의 send() 함수가 정확히 그 일을 해요 — ‘실패’처럼 보이는 302가 사실은 정상 절차라는 것, 기억해 두세요.

그림으로 보기 — 데이터가 어떻게 쌓일까

마치 엽서를 보내는 것과 같아요. 피코가 지금 잰 숫자를 엽서에 적어 ‘구글 시트’라는 우편함으로 보내면, 시트에 새 줄이 하나씩 차곡차곡 쌓입니다. 👇

1단계 · 구글 쪽 준비 (한 번만 · 차근차근)

이 단계는 컴퓨터 브라우저에서만 진행합니다(피코는 아직 책상 위에). 화면이 여러 번 바뀌지만 순서대로 하면 5분이면 끝나요. 구글 계정이 필요합니다.

⚠️ ⚠️ 개인 구글 계정으로 하세요 (학교 계정 ✗)
학교에서 발급한 계정(구글 워크스페이스)은 관리자 설정에 따라 Apps Script가 막혀 있거나, 배포할 때 액세스 권한에 ‘모든 사용자’ 선택지가 아예 안 뜰 수 있어요(‘○○학교의 모든 사용자’까지만 나옴). 그러면 로그인을 못 하는 피코는 무조건 실패합니다. 뒤에서 ‘모든 사용자’가 목록에 안 보이면 십중팔구 이것 때문 — 개인 @gmail.com 계정으로 다시 진행하세요.
  1. 새 구글 시트 만들기주소창에 sheets.new를 입력하면 새 시트가 열려요. (로그인이 안 돼 있으면 로그인 화면이 먼저 뜹니다.) 왼쪽 위 제목을 ‘우리반 공기질’처럼 바꾸고, 1행에 시각·값이라고 적어 둡니다.
  2. Apps Script 열기시트 메뉴 확장 프로그램 → Apps Script를 누르면 코드 편집기가 새 탭으로 열려요. (‘확장 프로그램’ 메뉴가 안 보이면 화면이 좁은 거예요 — 창을 넓혀 보세요.)
  3. 코드 붙여넣기 → 저장편집기에 이미 적힌 function myFunction()…을 전부 선택(Ctrl+A · 맥은 ⌘A)해 지우고, 아래 코드를 통째로 붙여넣으세요. 파일 이름은 Code.gs 그대로 두고 저장(💾)합니다.
Apps Script 코드 (Code.gs 에 붙여넣기)JAVASCRIPT
function doGet(e) {
  const sh = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sh.appendRow([new Date(), Number(e.parameter.value)]);   // [시각, 값] 한 줄 추가
  return ContentService.createTextOutput("OK");
}
ℹ️ 이 다섯 줄이 하는 일
doGet은 누군가 이 웹앱 주소를 열 때마다 실행되는 함수예요. 주소 뒤에 붙어 온 value를 꺼내(e.parameter.value) 시트 맨 아래에 [지금 시각, 값] 한 줄을 추가하고(appendRow), ‘OK’라고 답합니다. 우편함에 편지가 오면 도장 찍고 서랍에 넣는 일을 코드 다섯 줄이 하는 거죠. 가운데 Number(…)는 문자로 도착한 값을 숫자로 바꿔서 넣는 부분 — 이래야 나중에 평균·차트가 제대로 됩니다.
  1. 시간대를 서울로왼쪽 프로젝트 설정(⚙️) → 시간대 → (GMT+09:00) 서울로 바꿉니다. 안 바꾸면 기록 시각이 미국 시간으로 적혀서 나중에 그래프가 통째로 어긋나요. (그래도 시각이 이상하면 시트로 돌아가 파일 → 설정 → 시간대도 서울인지 확인하세요 — 표시 시간대는 시트 설정을 따릅니다.)
  2. 웹 앱으로 배포 시작오른쪽 위 파란 배포 → 새 배포를 누르고, ‘유형 선택’ 옆 톱니바퀴(⚙️)를 눌러 웹 앱을 고릅니다. (처음이면 ‘프로젝트 이름을 입력하세요’ 창이 먼저 떠요 — ‘공기질기록’ 등 아무 이름이나 적고 넘어가면 됩니다.)
  3. 권한 설정 후 배포실행: 나 · 액세스 권한: 모든 사용자로 두고 배포를 누르세요. (피코는 로그인을 못 하니 꼭 ‘모든 사용자’!) 기본값(‘나만’)으로 두면 아무 오류 없이 조용히 실패합니다. ‘모든 사용자’가 목록에 없으면 학교 계정이에요 — 위 경고 콜아웃을 보세요.
  4. 권한 승인 (처음 한 번만)‘액세스 승인’ → 내 구글 계정 선택 → ‘확인되지 않은 앱’ 경고가 떠도 정상 → 왼쪽 아래 고급 → ‘…(으)로 이동(안전하지 않음)’ → 허용. (화면에 따라 ‘허용’ 대신 항목에 체크하고 ‘계속’을 누르는 모양일 수 있어요 — 같은 뜻입니다.) 이 경고 화면에서 90%가 멈칫하는데, 아래 설명을 읽고 침착하게 통과하세요.
  5. 웹 앱 주소 복사마지막에 나오는 ‘웹 앱 URL’(/exec로 끝나는 긴 주소)의 복사를 누르세요. (디플로이 ID가 아니라 URL이에요! 브라우저 주소창의 편집 화면 주소도 아닙니다.) 메모장에 붙여 두면 다음 단계가 편해요.
💡 겁먹지 마세요 — ‘확인되지 않은 앱’ 경고
빨간/노란 경고 화면은 ‘구글이 아직 검토하지 않은 앱’이라는 뜻일 뿐이에요. 남이 만든 수상한 앱이 아니라 내가 방금 만든 스크립트라 안전합니다. 왼쪽 아래 ‘고급’ → ‘…(으)로 이동(안전하지 않음)’ → ‘허용’ 순서로 넘어가면 됩니다.
주소는 이 브라우저에만 저장되고 어디로도 전송되지 않아요. 붙여넣으면 아래 2단계 완성 코드에 자동으로 들어가고, 중간 점검용 테스트 링크도 만들어 줍니다.

중간 점검 — 피코 없이 웹앱부터 시험! 위 상자에 주소를 붙여넣으면 🧪 테스트 링크가 생겨요. 링크를 누르거나, 직접 주소 뒤에 ?value=99를 붙여 새 탭에서 열어 보세요.

  • 브라우저 화면에 OK라고 떴나요?
  • 시트 탭으로 돌아가면 [방금 시각, 99] 한 줄이 생겼나요?
  • 한 번 더 열면(새로고침) 줄이 하나 더 늘어나나요?
🔑 이 중간 점검이 반이에요
여기서 OK가 뜨면 구글 쪽은 완성 — 이후 문제가 생겨도 범인은 피코 쪽(와이파이·주소 오타)으로 좁혀집니다. 반대로 여기서 안 되면 피코를 붙여도 절대 안 돼요. ‘한 번에 다 만들고 몰아서 시험’ 대신 ‘반 만들고 반 시험’ — 디버깅의 기본기입니다.
ℹ️ 나중에 코드를 고치면 — 새 버전으로 재배포
Apps Script 코드를 수정했다면 배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포로 다시 배포해야 반영됩니다. (주소는 그대로예요.) 편집기에서 저장만 하면 옛 코드가 계속 돕니다.

2단계 · 피코 연결 — 1분마다 자동 기록

ℹ️ 먼저 — 와이파이 정보 파일 (wifi_config.py)
이 코드는 와이파이 정보를 wifi_config.py에서 불러옵니다. 1장에서 이미 만들었다면 그대로 쓰면 돼요. 없다면 main.py와 같은 위치에 새로 만들어 두 줄만 적어 저장하세요.

WIFI_SSID = "우리_와이파이_이름"
WIFI_PASSWORD = "비밀번호"

(피코는 2.4GHz 와이파이만 됩니다.)

라즈베리파이 피코 2 W에서 돌아가는 마이크로파이썬(MicroPython) 코드를 만들어줘. 센서값을 구글 시트에 자동 기록하는 장치야. - 가스센서(MQ-2)를 아날로그 입력인 26번 핀으로 읽어, 60초마다 구글 시트에 한 줄씩 기록하고 싶어. - 값이 출렁이지 않게 여러 번 읽어 평균을 낸 값을 보내줘. - 기록 방법: 구글 앱스 스크립트(Apps Script)로 배포한 웹 앱 주소('/exec'로 끝나는 전체 주소) 뒤에 '?value=측정값'을 붙여 요청을 보내는 방식이야. - 외부 라이브러리는 설치하지 말고 피코 기본 내장 기능(socket, ssl)만 써. 보안 인증서 확인은 건너뛰어도 되고, 구글이 다른 주소로 한 번 건너뛰게 하면(리다이렉트) 그것까지 따라가서 마무리해줘. - 와이파이 정보는 설정 파일(wifi_config.py)에서 불러오고, 웹 앱 주소와 보내는 주기는 코드 맨 위에 둬. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.

Step 2. 직접 만들지 않아도, 아래 완성본을 쓰면 됩니다. 1단계의 주소 상자에 붙여넣었다면 코드에 이미 내 주소가 들어가 있어요 — 펼쳐서 복사만 하면 끝! (상자를 안 썼다면 코드 위쪽 WEB_APP_URL = "…" 줄의 따옴표 안 주소만 직접 바꾸세요. 양쪽 따옴표 "는 지우지 말고요.)

# 공기질 기록 노트 — 센서값을 구글 시트에 1분마다 자동 기록 (설치할 것 없음)
import network, socket, ssl, time, gc
from machine import ADC, Pin
from wifi_config import WIFI_SSID as SSID, WIFI_PASSWORD as PASSWORD

# ↓ 이 따옴표 안 주소 전체를, 구글에서 복사한 웹 앱 주소(.../exec)로 바꾸세요
WEB_APP_URL = "https://script.google.com/macros/s/...여기에_주소_붙여넣기.../exec"
INTERVAL = 60                 # 몇 초마다 보낼지 (60 = 1분)
gas = ADC(Pin(26))           # 가스센서 (그로브 A0)

def read_avg(n=20):           # 3장에서 배운 대로 — 여러 번 읽어 평균(출렁임 줄이기)
    return sum(gas.read_u16() for _ in range(n)) // n

def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(SSID, PASSWORD)
    print("Wi-Fi 연결 중", end="")
    t = 20
    while not wlan.isconnected() and t > 0:
        print(".", end=""); time.sleep(0.5); t -= 1
    print("\nOK" if wlan.isconnected() else "\n실패")
    return wlan.isconnected()

def https_get(url):           # 전체 주소(https://...)를 받아 요청
    host, _, path = url[8:].partition("/")
    gc.collect()
    s = socket.socket()
    try:                      # 도중에 실패해도 소켓은 꼭 닫는다 (밤새 돌려도 안 새게)
        s.connect(socket.getaddrinfo(host, 443)[0][-1])
        try:
            ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
            ctx.verify_mode = ssl.CERT_NONE
            s = ctx.wrap_socket(s, server_hostname=host)
        except AttributeError:
            s = ssl.wrap_socket(s, server_hostname=host)
        s.write(("GET /%s HTTP/1.0\r\nHost: %s\r\nConnection: close\r\n\r\n"
                 % (path, host)).encode())
        buf = b""
        while True:
            c = s.read(512)
            if not c:
                break
            buf += c
        return buf
    finally:
        s.close()

def send(value):
    resp = https_get(WEB_APP_URL + "?value=" + str(value))
    head = resp.split(b"\r\n\r\n", 1)[0]
    if b" 302 " in head or b" 301 " in head:     # 구글이 다른 주소로 넘기면 따라가기
        for line in head.split(b"\r\n"):
            if line.lower().startswith(b"location:"):
                https_get(line.split(b":", 1)[1].strip().decode())
                break

if connect_wifi():
    n = 0
    while True:
        v = read_avg()
        try:
            send(v)
            n += 1
            print("시트로 보냄:", v, "(누적 %d줄)" % n)
        except Exception as e:
            print("실패(잠시 뒤 다시 시도):", e)
            if not network.WLAN(network.STA_IF).isconnected():
                connect_wifi()          # 밤새 기록 중 와이파이가 끊겨도 다시 붙는다
        time.sleep(INTERVAL)
💡 잘 되는지 확인하는 법
코드를 실행한 채 구글 시트를 열어 두세요. 1분마다 줄이 하나씩 스르륵 늘어나면 성공! Thonny 아래 셸(Shell) 칸에 시트로 보냄: 1234 같은 메시지가 1분마다 찍혀도 잘 가는 거예요. 안 되면 아래 ‘자주 막히는 곳’으로.
🔑 둘은 ‘value’라는 이름으로 짝이에요
피코는 주소 뒤에 ?value=1234처럼 값을 붙여 보내고, Apps Script(1단계 코드)는 그 value를 꺼내 시트 ‘값’ 칸에 적습니다. 양쪽 이름이 같아서 짝이 맞는 거예요. 나중에 온도 등 값을 하나 더 보내고 싶으면 양쪽에 같은 이름을 하나 더 늘리면 됩니다.
ℹ️ 왜 딱 60초마다 안 와요?
INTERVAL은 ‘쉬는 시간’만 정해요. 한 바퀴에는 쉬는 시간 + 인터넷으로 보내는 시간이 같이 들어가고, 전송 시간이 매번 조금씩 달라서 실제 간격은 설정값보다 살짝 길고 들쭉날쭉합니다. ‘정확한 초’보다 ‘꾸준히 기록’이 목적이라 괜찮아요.

Step 3. 1분마다 줄이 쌓이는 걸 확인했다면, 같은 대화에서 ③으로 더 똑똑하게 만들어 봐요.

✨③ 프롬프트 개선 — 기록을 더 똑똑하게 (이어서 복사)
방금 만든 구글 시트 기록 코드를 이어서 개선해줘. - 평소에는 5분마다 보내다가, 직전 값보다 크게 튀면(예: 1.5배 이상) 즉시 보내게 해줘. 조용할 땐 데이터를 아끼고, 사건이 나면 놓치지 않게. - 16번 핀의 열 칸 LED 바(WS2813, 타이밍 값 네 개 280, 515, 515, 745 지정 필수)로 전송 순간에 초록 불이 한 번 반짝이게 해줘. 보내는 게 눈에 보이게. - 와이파이가 잠깐 끊겨도 프로그램이 죽지 않고, 다시 연결해서 계속 기록하게 해줘. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.

밤새 기록하기 — 시간이 데이터를 만든다

이 장의 진짜 실험은 수업이 끝난 뒤 시작됩니다. 우리가 집에 간 사이에도 피코는 1분마다 꼬박꼬박 기록해요 — 내일 아침, 수백 줄의 데이터가 우리를 기다립니다.

  1. main.py로 저장코드를 피코에 main.py 이름으로 저장하세요(0장 참고). 그래야 컴퓨터 없이 전원만 꽂아도 자동 실행됩니다.
  2. 전원 확보USB 어댑터(휴대폰 충전기면 충분)를 교실 콘센트에 꽂고 피코를 연결합니다. 보조배터리도 되지만 밤새 버티는지는 용량에 달렸어요.
  3. 떠나기 전 확인시트에 줄이 늘어나는 걸 확인하고 자리를 떠나세요. ‘아마 되겠지’는 다음 날 아침 빈 시트로 돌아옵니다. 중간 점검 때 넣은 테스트 줄(99)은 지우고 시작하면 내일 통계가 깨끗해요.
  4. 다음 날 아침시트를 열어 밤새 쌓인 데이터를 확인! 이제 아래 ‘탐구하기’로 넘어갑니다.
⚠️ 학교 와이파이가 밤에 꺼진다면
일부 학교는 야간에 와이파이를 끄거나 기기 간 통신을 차단해요. 그럴 땐 대안 두 가지 — ① 수업 중 점심시간 2~3시간만 기록해도 탐구는 충분히 됩니다. ② 데이터 무제한 폰이 있다면 핫스팟을 켜 둔 채 두는 방법도 있어요(배터리·요금 확인!). 목적은 ‘밤샘’이 아니라 ‘내가 안 보는 시간의 데이터’입니다.

쌓인 데이터로 탐구하기 — 이 장의 본체

기록은 수단이고 탐구가 목적이에요. 시트에 쌓인 수백 줄은 그냥 보면 숫자 더미지만, 그래프로 바꾸는 순간 이야기가 됩니다.

  1. 차트 그리기시각·값 두 열을 드래그로 선택 → 메뉴 삽입 → 차트. 차트 종류를 라인(선) 차트로 바꾸면 시간에 따른 곡선이 나타나요.
  2. 위험 구간 색칠값 열을 선택 → 서식 → 조건부 서식 → ‘다음보다 큼’에 3장에서 정한 WARNING 값을 넣고 배경을 노랑으로. 위험 시간대가 시트에서 한눈에 보여요.
  3. 통계 한 줄빈 칸에 =MAX(B2:B), =MIN(B2:B), =AVERAGE(B2:B)를 넣어 밤새 최고·최저·평균을 구합니다.

자주 하는 실수

❌ 브라우저 테스트(?value=99)부터 안 됨
원인배포 설정 문제 — 피코 이전 단계.
해결1단계로 돌아가 액세스 권한 ‘모든 사용자’, 주소가 /exec로 끝나는지부터 확인하세요. 여기가 안 되면 피코는 절대 안 됩니다.
❌ 브라우저는 OK인데 피코만 실패
원인와이파이 문제이거나 주소를 잘못 붙여넣음.
해결셸의 와이파이 메시지를 확인하고(2.4GHz만!), WEB_APP_URL에 /exec 전체 주소가 따옴표 안에 정확히 들어갔는지 보세요. 주소 앞뒤가 잘리는 실수가 흔해요.
❌ 시트에 아무것도 안 쌓임
원인웹앱 액세스 권한이 ‘모든 사용자’가 아님.
해결배포를 모든 사용자로 다시 하세요. 코드 수정 후엔 배포 관리 → 편집 → 새 버전으로 재배포해야 반영됩니다.
❌ ImportError: no module named 'wifi_config'

해결위 2단계 안내대로 wifi_config.py를 main.py와 같은 위치에 만들고 와이파이 두 줄을 적으세요.
❌ 셸에 ‘실패’라고 떠요
원인잠깐 인터넷이 끊겼을 때 그래요.
해결한두 번은 괜찮아요 — 다음 차례에 다시 보냅니다. 계속 그러면 INTERVAL을 늘려 보세요.
❌ 시각이 한국시간과 다름
원인Apps Script 프로젝트 또는 시트의 시간대가 기본(미국).
해결Apps Script 프로젝트 설정(⚙️) → 시간대 → 서울, 그리고 시트 쪽 파일 → 설정 → 시간대도 서울인지 확인하세요. 이미 쌓인 줄의 시각은 안 바뀌니 초반에 확인!
❌ 아침에 보니 기록이 중간에 끊김
원인전원이 뽑혔거나 야간에 와이파이가 꺼짐.
해결콘센트·어댑터를 확인하고, 학교망 야간 차단이면 ‘점심시간 기록’으로 바꾸세요. 끊긴 시각 자체도 데이터예요 — 언제 끊겼는지 그래프로 찾아보세요.

스스로 점검하기

피코가 구글 로그인 없이 시트에 쓸 수 있는 이유는?
Apps Script 웹앱을 ‘모든 사용자’로 배포해, URL만 알면 누구나(피코도) 호출할 수 있게 했기 때문. 로그인은 웹앱이 대신 해 줍니다.
이번 장에서 데이터가 흐르는 방향은 5장과 어떻게 다른가요?
5장은 피코가 인터넷에서 받아 왔고(Open-Meteo), 이번 장은 피코가 인터넷으로 보냅니다(시트). 둘 다 피코가 클라이언트인 건 같아요.
피코를 붙이기 전에 웹앱만 따로 시험하는 방법은?
브라우저에서 웹앱주소?value=99를 열어 OK와 시트의 새 줄을 확인합니다. ‘반 만들고 반 시험’이 디버깅의 기본기예요.
보내는 간격을 바꾸려면?
코드 맨 위 INTERVAL 숫자를 바꾸면 됩니다. 60이면 1분, 300이면 5분마다.
‘실시간으로 보기’는 못 하고 ‘기록’만 할 수 있는 질문의 예는?
‘어젯밤 언제 가장 나빴나’, ‘환기하면 몇 분 만에 돌아오나’, ‘창가와 복도 중 어디가 좋나’ — 모두 시간·비교가 필요한 질문들입니다.
