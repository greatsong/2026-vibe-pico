# 브리프(내용 가이드) — ML 확장판 부록 「라즈베리파이 5 세팅 A to Z」

독자: 고등학생(리눅스 처음). 라즈베리파이를 한 번도 써 보지 않았고, 모니터 없이 PC에서 원격으로 세팅함
문체: 해요체(~해요, ~예요)로 통일. 친절한 설명체. 청유("~해 보세요") 남용 금지, 평서 위주
맥락: 웹 교재 부록의 설명 문단. 각 블록 바로 옆에 단계 목록과 명령어 코드가 따로 있으므로 명령어를 되풀이하지 말고 '왜 이렇게 하는지'를 풀어 준다
공통 지시: 블록 하나의 출력은 문단 하나. 빈 줄로 나누지 말 것. 우회 표현('~하는 셈이에요') 대신 직접 서술. 은유·의인화·과장 금지. 대시(—)로 문장 잇지 말 것. HTML 태그는 KEEP에 있는 것만 사용. 각 블록은 짧게

[블록 15] 위치: 'G. PC에서 SSH로 접속하기' 맨 앞, 터미널이 처음인 학생을 위한 설명 / 역할: 본문
- 사실: 터미널(명령 창)은 마우스 대신 글자로 컴퓨터에 명령하는 프로그램. Windows에서는 PowerShell, Mac에서는 터미널 앱을 씀
- 사실: 커서가 깜빡이는 줄의 앞부분을 프롬프트라 부르고, 그 뒤에 명령을 입력한 뒤 Enter를 누르면 실행됨
- 사실: SSH로 접속한 뒤에도 같은 창을 쓰지만, 입력한 명령은 PC가 아니라 라즈베리파이에서 실행됨. 프롬프트 앞부분이 라즈베리파이 이름으로 바뀌는 것으로 구분함
- 사실: 명령은 한 글자, 띄어쓰기 하나만 달라도 동작하지 않으므로 교재의 복사 버튼으로 복사해 붙여 넣음
- KEEP: <b>프롬프트</b>
- 분량: 4~5문장
