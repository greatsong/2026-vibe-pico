# 브리프(내용 가이드) — ML 확장판 부록 「라즈베리파이 5 세팅 A to Z」

독자: 고등학생(리눅스 처음). 라즈베리파이를 한 번도 써 보지 않았고, 모니터 없이 PC에서 원격으로 세팅함
문체: 해요체(~해요, ~예요)로 통일. 친절한 설명체. 청유("~해 보세요") 남용 금지, 평서 위주
맥락: 웹 교재 부록의 설명 문단. 각 블록 바로 옆에 단계 목록과 명령어 코드가 따로 있으므로 명령어를 되풀이하지 말고 '왜 이렇게 하는지'를 풀어 준다
공통 지시: 블록 하나의 출력은 문단 하나. 빈 줄로 나누지 말 것. 우회 표현('~하는 셈이에요') 대신 직접 서술. 은유·의인화·과장 금지. 대시(—)로 문장 잇지 말 것. HTML 태그는 KEEP에 있는 것만 사용. 각 블록은 짧게

[블록 1] 위치: 부록 도입 / 역할: lead
- 사실: 라즈베리파이 5는 손바닥만 한 컴퓨터이고 리눅스 운영체제(Raspberry Pi OS)로 동작함
- 사실: 이 부록에서는 모니터와 키보드를 연결하지 않고, PC에서 원격으로 접속해 모든 설정을 함
- 사실: 부품 준비부터 운영체제 설치, 원격 접속, BirdNET 설치, 전원을 켜면 서버가 저절로 시작하게 하는 설정까지 차례로 다룸
- 사실: 명령어는 한 줄씩 복사해 붙여 넣고, 결과가 예상 화면과 같은지 확인한 뒤 다음으로 넘어감
- KEEP: <b>한 줄씩</b>
- 분량: 3~4문장

[블록 2] 위치: 'A. 준비물' / 역할: 본문
- 사실: 라즈베리파이 5, 공식 27W 전원 어댑터, 팬이 달린 공식 케이스, 64GB microSD, 카드 리더가 필요함
- 사실: PC는 Windows 10 이상 또는 macOS 13 이상이어야 운영체제 설치 프로그램(Raspberry Pi Imager)을 쓸 수 있음
- 사실: 교실 공유기의 Wi-Fi 이름과 비밀번호를 미리 알아 둠. 아이디를 입력해 로그인하는 학교 Wi-Fi는 이 방법으로 연결할 수 없음(O 단계)
- 분량: 3문장

[블록 3] 위치: 'B. 조립' / 역할: 본문
- 사실: 케이스의 팬 선을 보드의 팬 연결 단자에 꽂고 뚜껑을 닫음
- 사실: 라즈베리파이 5는 전원을 꽂으면 버튼을 누르지 않아도 바로 켜지므로, 전원은 microSD를 넣은 뒤 가장 마지막에 연결함
- 사실: 전원 어댑터는 반드시 공식 27W를 씀. 휴대폰 충전기는 전압이 모자라 느려지거나 microSD가 망가질 수 있음
- KEEP: <b>가장 마지막</b>
- 분량: 3문장

[블록 4] 위치: 'C·D. 운영체제 굽기' / 역할: 본문
- 사실: 모니터가 없으므로 첫 부팅 때 바로 Wi-Fi에 접속하고 원격 접속을 받을 수 있도록, 굽기 전에 사용자 이름, 비밀번호, Wi-Fi, SSH를 모두 정해 둠
- 사실: 이 설정을 건너뛰면 첫 부팅 때 화면으로만 설정을 물어서 모니터 없이는 접속할 수 없음. 예전의 기본 계정(pi)도 없어졌음
- 사실: 지역은 서울을 고름. 지역이 Wi-Fi 사용 규칙(국가)과 시간대를 정하고, 목록에서 바로 옆에 있는 다른 도시를 고르기 쉬움
- 사실: 호스트 이름은 모둠마다 다르게 정함(예 bird-1, bird-2). 모두 같은 이름이면 어느 라즈베리파이에 접속하는지 알 수 없음
- 사실: 운영체제는 화면이 없는 Lite 판을 고름. 서버로만 쓰므로 가볍고 빠름
- KEEP: <b>모둠마다 다르게</b>
- 분량: 5~6문장

[블록 5] 위치: 'E·F. 첫 부팅과 주소 찾기' / 역할: 본문
- 사실: 첫 부팅은 카드 공간을 늘리고 설정을 적용하느라 몇 분 걸리므로 기다림
- 사실: PC에서 '호스트이름.local'로 응답이 오면 라즈베리파이가 공유기에 연결된 것
- 사실: 응답이 없으면 공유기 관리 페이지의 연결 기기 목록이나 휴대폰 네트워크 검색 앱으로 IP 주소를 찾음
- 분량: 3문장

[블록 6] 위치: 'G. PC에서 SSH로 접속하기' / 역할: 본문
- 사실: SSH는 PC의 명령 창에서 다른 컴퓨터에 명령을 입력하게 해 주는 방법
- 사실: 처음 접속할 때 이 컴퓨터를 믿겠냐는 질문이 나오면 yes라고 입력함
- 사실: 비밀번호는 입력해도 화면에 아무것도 표시되지 않음. 그대로 입력하고 Enter를 누름
- 사실: 줄 앞에 '사용자이름@호스트이름'이 보이면 이제부터 입력하는 명령은 라즈베리파이에서 실행됨
- KEEP: <b>yes</b>
- 분량: 4문장

[블록 7] 위치: 'H. 업데이트' / 역할: 본문
- 사실: 설치 직후에는 보안 업데이트와 고친 부분을 받기 위해 업데이트를 먼저 함
- 사실: sudo가 붙은 명령은 관리자 권한으로 실행되고, 실행할 때마다 비밀번호를 물음
- 사실: 업데이트는 인터넷 속도에 따라 몇 분 이상 걸릴 수 있음
- KEEP: <code>sudo</code>
- 분량: 3문장

[블록 8] 위치: 'I. 작업 폴더와 가상환경' / 역할: 본문
- 사실: 최신 라즈베리파이 운영체제는 시스템 전체에 파이썬 패키지를 설치하지 못하게 막아 두고, 시도하면 externally-managed-environment 오류가 남
- 사실: 그래서 bird 폴더 안에 이 프로젝트만 쓰는 가상환경(venv)을 만들고 그 안에 설치함
- 사실: 가상환경을 켜면 줄 앞에 (venv)가 보이고, SSH로 새로 접속할 때마다 다시 켜야 함
- KEEP: <code>(venv)</code>
- 분량: 3~4문장

[블록 9] 위치: 'J. BirdNET과 Flask 설치' / 역할: 본문
- 사실: BirdNET은 새소리 판정 AI 패키지이고, Flask는 브라우저와 피코의 요청을 받는 웹 서버 패키지
- 사실: 설치는 몇 분 걸리고, 끝나면 두 패키지를 불러오는 한 줄 명령으로 설치가 잘 되었는지 확인함
- 분량: 2~3문장

[블록 10] 위치: 'K. 서버 받고 첫 실행' / 역할: 본문
- 사실: 교재 사이트에서 서버 파일을 그대로 내려받으므로 코드를 직접 입력하지 않아도 됨
- 사실: 첫 실행 때 BirdNET 모델을 내려받으므로 인터넷이 필요하고, 한 번 받은 뒤에는 다시 받지 않음
- 사실: 화면에 나온 주소를 PC 브라우저에서 열어 판정 페이지가 보이면 서버가 동작하는 것
- 분량: 3문장

[블록 11] 위치: 'L. 전원만 켜면 서버가 시작되게' / 역할: 본문
- 사실: 지금은 SSH 창을 닫으면 서버도 꺼짐
- 사실: systemd에 서비스로 등록하면 라즈베리파이가 켜질 때 서버가 저절로 시작되고, 오류로 멈추면 다시 시작됨
- 사실: 등록하기 전에 손으로 켠 서버는 Ctrl+C로 먼저 끔. 두 서버가 같은 번호(8000)를 쓰려고 하면 하나가 시작하지 못함
- 사실: 서버가 화면에 쓰던 글은 로그 명령으로 볼 수 있음
- KEEP: <code>systemd</code>
- 분량: 4문장

[블록 12] 위치: 'M. 주소 고정과 AP 격리' / 역할: 본문
- 사실: 공유기는 기기가 다시 켜질 때 다른 주소를 줄 수 있고, 그러면 피코 코드의 SERVER 주소가 맞지 않게 됨
- 사실: 공유기 관리 페이지에서 라즈베리파이의 MAC 주소에 항상 같은 IP를 주도록 예약하는 방법을 라즈베리파이 공식 문서가 권함
- 사실: 공유기에 AP 격리(무선 격리)가 켜져 있으면 같은 Wi-Fi에 연결된 기기끼리 서로 통신할 수 없음
- 사실: 공유기 목록에는 라즈베리파이가 보이는데 PC에서 응답이 없으면 AP 격리를 의심하고, 공유기 관리자에게 끄도록 요청하거나 수업용 공유기를 따로 씀
- KEEP: <b>AP 격리</b>
- 분량: 4~5문장

[블록 13] 위치: 'N. 온도·전원 확인과 안전하게 끄기' / 역할: 본문
- 사실: 종료하지 않고 전원을 뽑으면 microSD의 파일이 망가질 수 있으므로 종료 명령으로 끈 뒤 LED가 빨간색이 되면 전원을 뽑음
- 사실: Lite 판에서는 보드의 전원 버튼을 한 번 눌러도 안전하게 종료가 시작됨
- 사실: 온도와 전원 상태를 확인하는 명령으로 전원 부족이나 과열 기록이 있는지 볼 수 있음
- 분량: 3문장

[블록 14] 위치: 'O·P. 이럴 때는' / 역할: 본문
- 사실: 아이디와 비밀번호를 함께 입력하는 학교 Wi-Fi(WPA2-Enterprise)는 운영체제 굽기 단계에서 설정할 수 없으므로 수업용 공유기를 따로 두는 것이 가장 간단함
- 사실: microSD에 운영체제를 다시 구우면 라즈베리파이의 신분 정보가 바뀌어, 같은 이름으로 접속할 때 PC가 경고를 내고 접속을 막음
- 사실: 이때는 PC에 저장된 옛 정보를 지우는 명령을 한 번 실행한 뒤 다시 접속함
- 분량: 3문장
