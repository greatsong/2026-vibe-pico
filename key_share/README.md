# 🔑 연수용 키 배포 (key_share)

교사 연수에서 **강사의 API 키를 연수생에게 안전하게 복붙 전달**하기 위한 단일 HTML 도구입니다.
백엔드가 없어 어떤 정적 호스팅에도 그대로 올라가며, **키가 파일에 박히지 않습니다**(런타임에 강사가 입력).

> 공개 주소: **https://greatsong.github.io/2026-vibe-pico/key_share/**

---

## 어떻게 동작하나 (보안 모델)

```
[강사] 키 입력 + 접근 코드 ──암호화(AES-GCM)──▶ 링크의 #k=... 조각 + QR
                                                  │  (서버로 전송 안 됨)
[연수생] QR/링크로 접속 ──접근 코드 입력──▶ 복호화 ──▶ 키·코드 복사
```

- 키는 URL의 `#`(fragment) 뒤에 **암호화되어** 담깁니다. fragment는 **서버로 전송되지 않아** 호스팅 로그·히스토리에 남지 않습니다.
- 링크가 새어나가도 **접근 코드(현장에서 구두로 공지)** 없이는 복호화되지 않습니다 → *링크 유출 ≠ 키 유출*.
- 암호화는 브라우저 내장 **WebCrypto(PBKDF2 + AES-256-GCM)** 로 처리. 외부 서버·라이브러리에 키를 보내지 않습니다.

> ⚠️ 한 번 복사된 키는 연수생 기기에 남아 **회수가 불가능**합니다. 아래 "필수 가드레일"을 반드시 지키세요.

## 사용법

### 1. 강사 (👩‍🏫 강사 탭)
1. **API 키**, **키 이름(라벨)**, **접근 코드**(4자 이상) 입력
2. **🔗 연수생 링크 · QR 생성** 클릭
3. 나타난 화면(**QR + 링크 + 접근 코드**)을 **그대로 화면 공유**
   - 입력값은 이 브라우저(localStorage)에만 저장되어 다음에 자동 복원됩니다.
   - 공용 PC라면 끝나고 **🧹 이 기기에서 저장 삭제**를 누르세요.

### 2. 연수생 (🧑‍🎓 연수생 탭)
- **폰**: QR 스캔 → 페이지 열림 → 접근 코드 입력 → **🔓 키 보기** → 복사
- **노트북(키보드가 빠른 환경)**: 베이스 주소 접속 → "링크 붙여넣기"에 강사가 준 링크/코드 붙여넣기 → 접근 코드 입력

### 3. 코드 (📋 코드 탭)
- 예제 코드의 `{{API_KEY}}` 가 받은 키로 **자동 치환**되어 복사됩니다.
- 강사 탭에서 스니펫을 추가하면 연수생 코드 탭에도 함께 전달됩니다.

## 배포

이미 GitHub Pages(`main` 루트)로 배포되어 있습니다. 파일을 수정해 `main`에 푸시하면 몇 분 뒤 반영됩니다.

다른 곳에 올릴 때도 **`index.html` 파일 하나만** 올리면 됩니다. 단, 암호화(WebCrypto)는 보안 컨텍스트에서만 동작하므로 **`https://` 또는 `http://localhost`** 로 열어야 합니다. (`file://` 직접 열기는 일부 브라우저에서 막힘)

로컬 미리보기:
```bash
cd 2026-vibe-pico
python3 -m http.server 8765
# http://localhost:8765/key_share/
```

## ✅ 필수 가드레일 (전달 방식과 무관하게 반드시)

- **연수 전용 키**를 새로 발급 — 평소 쓰는 메인 키 금지
- **YouTube Data API 키**: Google Cloud Console에서 *API 제한 → YouTube Data API v3* 만 허용 (기본 무료 쿼터제라 금전 리스크 낮음)
- **Claude / OpenAI 등 유료 키**: 전용 키 + **Spend limit(사용 한도)을 낮게 하드 설정**
- 연수 종료 후 **즉시 키 폐기(revoke)** — 복사된 키는 회수 불가

## 기술 메모

- 의존성: QR 생성용 [`qrcodejs`](https://github.com/davidshimjs/qrcodejs) (CDN). 오프라인이면 QR 대신 링크 텍스트를 공유.
- 단일 파일, 빌드 불필요, `noindex` 메타 적용.
