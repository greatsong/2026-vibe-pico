학생 작품 갤러리 🖼️

피코로 만든 작품을 자유롭게 올리고, 친구들의 작품도 둘러보세요. 회원가입·로그인 없이 닉네임만으로 참여할 수 있어요.

⚠️ 아직 실제 갤러리 데이터베이스가 준비되지 않았어요
지금은 예시 작품으로 미리보기를 보여드리고 있어요. 담당 선생님이 gallery/pico_gallery_schema.sql을 Supabase SQL Editor에서 실행하면, 새로고침 시 자동으로 실제 갤러리로 바뀝니다.
❓ 처음이신가요? — 30초 사용법
  1. 둘러보기 — 카드의 바로가기를 누르면 그 작품이 새 창에서 열립니다.
  2. 골라 보기 — 위 구분 칩(자유 프로젝트 / 오픈 API / 수업 응용 / 기타)으로 원하는 것만 모아 보기.
  3. 응원하기 — ♡ 좋아요 + 한 줄 피드백 남기기.
  4. 내 작품 올리기 — 📮 작품 등록 탭 → 닉네임·구분·제목·URL·소개 → 갤러리에 게시하기.

작품 URL은 https로 시작해야 합니다. 로그인이 없는 버전이라 닉네임 사칭·중복 좋아요는 완전히 막지 못해요 — 수업용으로 감수한 한계입니다.

조건에 맞는 작품이 아직 없어요.

작품 URL과 소개를 입력하면 갤러리에 바로 게시됩니다. 로그인이 없으니 닉네임을 정확히 적어주세요.
