CHAPTER 03

우리반 공기질 대시보드 (웹)

MQ-2 센서로 우리반 공기 중 가스를 숫자로 읽고, 안전/주의/위험을 색과 그래프로 보여 주는 웹 대시보드(다크 테마)를 만듭니다.

🎯 이 장을 마치면
  • ADC로 가스센서 값을 읽고 전압·비율로 바꿀 수 있다
  • 이동 평균으로 값을 안정시킬 수 있다
  • 임계값으로 안전/주의/위험 상태를 판단해 웹으로 보여 준다
💡 왜 배우나요?

공기질은 눈에 안 보이죠. MQ-2 센서로 측정해 숫자 → 색 → 그래프로 바꾸면, 환기 타이밍을 한눈에 알 수 있어요. 센서값을 ‘판단(임계값)’하고 피코가 웹서버가 되어 스마트폰·PC로 보여 줍니다. 다음 장에선 폰을 켜지 않고 LED만으로 같은 공기질을 확인해 볼 거예요.

배선 — MQ-2 연결하기

센서값을 읽기 전에, MQ-2 가스센서를 먼저 연결해요. MQ-2는 2장의 LED와 달리 그로브 모듈이 아니라 핀헤더형이라, 그로브 암(Female) 점퍼 케이블로 잇습니다. (피코·쉴드까지 포함한 전체 조립 그림은 0장 · 하드웨어 조립을 참고하세요.)

🔑 MQ-2 → 그로브 A0 포트 (암 점퍼 케이블)
그로브 암 점퍼 케이블의 그로브 커넥터 쪽을 쉴드의 A0 포트(=GP26, 아날로그)에 꽂고, 반대쪽 까만 암 단자 4가닥을 센서에 새겨진 핀 글자를 보며 하나씩 꽂아요:

· 빨강 → 센서의 VCC 핀
· 검정 → 센서의 GND 핀
· 노랑 → 센서의 AO 핀 (아날로그 출력 — 우리가 읽는 값)
· 흰선 & 센서의 DO 핀 → 아무 데도 안 꽂고 비워 둠

⚠️ 이름이 닮았지만 서로 달라요 — 쉴드의 A0(에이·제로)는 그로브 케이블을 통째로 꽂는 포트이고, 센서의 AO(에이·오)는 노란선 한 가닥을 꽂는 핀이에요. 쉴드에는 노란선을 꽂을 낱개 핀이 없습니다.

gas_sensor = ADC(Pin(26))
  1. 그로브 커넥터를 A0 포트에암 점퍼 케이블의 그로브 쪽을 쉴드 A0(=GP26) 포트에 꽂습니다. LED(D16)와 헷갈리지 마세요 — 가스센서는 아날로그 A0.
  2. 빨강·검정·노랑 3가닥을 센서에센서 보드에 인쇄된 글자를 보며 빨강→VCC · 검정→GND · 노랑→AO. 센서 네 핀 중 노란선을 센서의 AO 핀(쉴드의 A0 포트와 다른 곳!)에 꽂는 게 이 배선의 핵심이에요.
  3. 흰선과 DO는 비워 두기케이블의 흰선, 그리고 센서의 DO 핀은 아무 데도 연결하지 않습니다. 우리는 아날로그 출력(AO)만 읽어요.
⚠️ 노란선은 반드시 센서의 AO 핀에 — DO 아님
MQ-2 핀은 VCC · GND · DO · AO 네 개예요. 노란선이 DO(디지털)에 잘못 꽂히면 값이 0이나 65535에 붙어 꿈쩍도 안 합니다. 아래 ‘따라하기’에서 값이 이상하면 제일 먼저 노란선이 센서의 AO 핀에 있는지 확인하세요. (센서 보드의 파란 네모=가변저항은 DO 감도 조절용이라 우리 실습과는 무관해요.)

핵심 개념

ADC (아날로그)
가스 농도 같은 ‘연속된 값’을 숫자로 바꿔 읽는 기능. 그로브 A0 = GP26. ADC(Pin(26))
read_u16()
0~65535 사이 값으로 읽습니다. 가스가 짙을수록 값이 커져요.
이동 평균
여러 번 읽어 평균 내면 값이 출렁이지 않고 안정됩니다. read_average()
임계값
SAFE / WARNING / DANGER를 나누는 기준 숫자. 환경마다 달라 보정이 필요해요.
🔬 더 알아보기 — ADC가 ‘전압’을 ‘숫자’로 바꾸는 원리 (볼트 변환)
센서는 가스 농도를 전압(아날로그)으로 내보냅니다. 0V~3.3V 사이의 ‘연속된’ 값이죠. 그런데 컴퓨터는 숫자만 다루니, 이 전압을 숫자로 바꿔야 합니다. 그 변환기가 ADC(Analog-to-Digital Converter, 아날로그→디지털 변환기)예요.

피코의 ADC는 실제로는 12비트(4096단계)로 재고, MicroPython의 read_u16()이 그 값을 0 ~ 65535(16비트 범위)로 늘려서 돌려줘요.
· 0V → 0
· 3.3V(최대) → 65535
· 그 사이는 비례. 따라서 숫자를 전압으로 되돌리면:
전압(V) = read_u16() / 65535 × 3.3

예) 읽은 값이 32768이면 → 32768/65535×3.3 ≈ 1.65V (딱 절반).

주의: MQ-2에서 ‘전압이 곧 가스 농도(ppm)’는 아닙니다. 정확한 ppm은 보정·계산이 필요해서, 수업에서는 상대적인 변화(평소보다 높다/낮다)를 보는 지표로 씁니다. 그래서 SAFE/WARNING/DANGER 임계값도 우리 교실에서 직접 보고 정합니다.
ℹ️ 센서는 예열이 필요해요
MQ-2는 전원을 넣고 1~2분 지나야 값이 안정됩니다. 처음 켜자마자 값이 크게 나와도 예열 전이라 그런 것이니 정상이에요.
ℹ️ 먼저 — 와이파이 정보 파일 만들기 (wifi_config.py)
대시보드 코드는 와이파이 정보를 wifi_config.py에서 불러옵니다. main.py와 같은 위치에 이 파일을 새로 만들고 두 줄만 적어 저장하세요.

WIFI_SSID = "우리_와이파이_이름"
WIFI_PASSWORD = "비밀번호"

(피코는 2.4GHz 와이파이만 됩니다.)

Step 3 · 전압·비율 변환PYTHON
# 원시값을 전압과 비율로 바꿔 보기
from machine import ADC, Pin
import time

gas_sensor = ADC(Pin(26))
while True:
    value = gas_sensor.read_u16()
    voltage = value / 65535 * 3.3
    percent = value / 65535 * 100
    print("ADC: %5d  |  %.2fV  |  %.1f%%" % (value, voltage, percent))
    time.sleep(0.5)

Step 4. 이제 완성형 대시보드를 만들어요. 이런 긴 코드는 손으로 치지 않아요 — AI에게 아래처럼 상황과 목표를 설명하면 만들어 줍니다.

def read_average(sensor, count=10):
    total = 0
    for _ in range(count):
        total += sensor.read_u16()
        time.sleep_ms(10)
    return total // count


def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(SSID, PASSWORD)
    print("Wi-Fi 연결 중", end="")
    timeout = 20
    while not wlan.isconnected() and timeout > 0:
        print(".", end="")
        time.sleep(0.5)
        timeout -= 1
    if wlan.isconnected():
        ip = wlan.ifconfig()[0]
        print(f"\n✅ 연결 완료!  →  http://{ip}")
        return ip
    print("\n❌ Wi-Fi 연결 실패")
    return None

MQ-2는 그로브의 어느 포트에 꽂나요?
