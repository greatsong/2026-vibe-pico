CHAPTER 02

LED로 내 감정 표현하기

WS2813 LED 바(10개)를 색과 움직임으로 자유자재로 다뤄, 마지막엔 내 기분을 표현하는 ‘감정 무드등’을 만듭니다.

🎯 이 장을 마치면
  • NeoPixel로 LED 한 칸·전체를 원하는 색으로 켤 수 있다
  • WS2813에 꼭 필요한 timing 인자를 이해한다
  • 10칸에 무지개·게이지를 표현할 수 있다
  • 색과 움직임을 조합해 내 감정을 LED로 표현할 수 있다
💡 왜 배우나요?

LED는 ‘숫자·상태를 빛으로 바꾸는’ 가장 직관적인 출력 장치예요. 색과 움직임만으로도 기쁨·평온·화남 같은 감정을 표현할 수 있죠. 이 장에서 10칸을 다루는 법을 익히면, 뒤의 공기질·날씨 장에서 데이터를 색으로 보여 주는 데에도 똑같이 씁니다.

핵심 개념 — timing이 진짜 중요해요

🔑 WS2813은 timing 인자가 필수
우리가 쓰는 LED는 WS2813 계열이라, MicroPython NeoPixel의 기본 타이밍과 안 맞습니다. 그대로 두면 색이 깨지거나 엉뚱한 칸이 켜져요. 그래서 반드시 이렇게 만듭니다:

TIMING = (280, 515, 515, 745)
np = NeoPixel(Pin(16), 10, timing=TIMING)

이 네 숫자는 0/1 신호의 길이(나노초)예요. 이번 연수의 모든 LED 코드 첫 줄에 들어갑니다.
ℹ️ LED가 60개짜리로 왔다면?
바꿀 곳은 딱 한 줄이에요. 코드 위쪽의 NUM = 10을 NUM = 60으로 바꾸면 끝입니다. (timing·핀은 그대로) fill·무지개·게이지·감정 무드등 모두 NUM을 기준으로 돌아서 자동으로 60칸에 맞춰집니다. 단, 60칸을 밝게 켜면 전류를 많이 먹으니 밝기는 더 낮춰 주세요.
NeoPixel
여러 개의 색 LED를 한 줄로 제어하는 도구. np[i] = (r, g, b)로 i번 칸 색을 정합니다.
write()
색을 정한 뒤 np.write()를 호출해야 실제 LED에 반영됩니다. 깜빡 잊기 쉬워요.
칸 번호 0~9
10개니까 np[0]부터 np[9]까지. 0부터 시작!
밝기는 낮게
(255,255,255)는 너무 밝고 전류도 많이 써요. (30,30,30) 정도면 충분히 보입니다.
🔬 더 알아보기 — timing=(280, 515, 515, 745)의 정체 (1선 통신과 GRB)
WS2813 같은 LED는 칸이 10개여도 데이터 선이 하나뿐이에요. 그래서 0과 1을 ‘펄스(전기 신호)의 길이’로 구분합니다. 이게 1-wire(원-와이어) 프로토콜이에요.

네 숫자는 나노초(ns, 10억분의 1초) 단위의 시간이고, 각각:
· T0H=280 — ‘0’을 보낼 때 켜 두는 시간
· T0L=515 — ‘0’을 보낼 때 꺼 두는 시간
· T1H=515 — ‘1’을 보낼 때 켜 두는 시간
· T1L=745 — ‘1’을 보낼 때 꺼 두는 시간

이 길이가 칩이 기대하는 값과 안 맞으면 0을 1로, 1을 0으로 잘못 읽어 색이 깨집니다. 칩 종류마다 기대 시간이 조금씩 달라, WS2813엔 이 네 값을 직접 지정해 주는 거예요.

또 하나, 사람은 색을 (빨강, 초록, 파랑) = RGB 순서로 생각하지만 이 LED는 내부적으로 GRB(초록·빨강·파랑) 순서로 데이터를 받습니다. 대부분의 펌웨어에서는 (r, g, b)로 쓰면 되지만, 혹시 빨강·초록이 바뀌어 보이면 순서를 조정하면 돼요.
🧯 예상 오류 — timing 누락이 이 장의 1순위
AI가 준 코드에 timing 인자가 빠진 채 오는 경우가 가장 많습니다. 색이 깨지거나 엉뚱한 칸이 켜지면 코드를 읽기 전에 먼저 Ctrl+F로 ‘timing’을 검색하게 하세요. 없으면 AI에게 “타이밍 값 네 개(280, 515, 515, 745)를 넣어줘”라고 다시 요청하면 됩니다. 이 ‘검색 → 재요청’ 한 동작을 이 장에서 전체가 몸에 익히면 4·5장의 LED 질문이 절반으로 줍니다.

from machine import Pin

import time

TIMING = (280, 515, 515, 745)        # ★ WS2813 전용 타이밍 (없으면 색이 깨집니다!)

np[0] = (40, 0, 0)                   # 0번 칸 빨강 (밝기는 낮게)
np.write()                           # write()를 해야 실제로 켜집니다
time.sleep(2)

np[0] = (0, 0, 0)                    # 끄기
np.write()

from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
NUM = 10
np = NeoPixel(Pin(16), NUM, timing=TIMING)

def fill(color):
    for i in range(NUM):
        np[i] = color
    np.write()

fill((0, 30, 0))     # 전체 초록
time.sleep(1)
fill((0, 0, 30))     # 전체 파랑
time.sleep(1)
fill((0, 0, 0))      # 전체 끄기

Step 3 · 무지개 10칸PYTHON
# 10칸에 무지개 펼치기 (HSV로 색상환 한 바퀴)
from machine import Pin
from neopixel import NeoPixel

TIMING = (280, 515, 515, 745)
NUM = 10
np = NeoPixel(Pin(16), NUM, timing=TIMING)
BRIGHT = 0.3                          # 밝기 0~1 (낮게 권장)

def hsv_to_rgb(h, s, v):
    c = v * s
    x = c * (1 - abs((h / 60) % 2 - 1))
    m = v - c
    if   h < 60:  r, g, b = c, x, 0
    elif h < 120: r, g, b = x, c, 0
    elif h < 180: r, g, b = 0, c, x
    elif h < 240: r, g, b = 0, x, c
    elif h < 300: r, g, b = x, 0, c
    else:         r, g, b = c, 0, x
    return (int((r + m) * 255), int((g + m) * 255), int((b + m) * 255))

for i in range(NUM):
    hue = i / NUM * 360               # 칸마다 색상 조금씩 다르게
    np[i] = hsv_to_rgb(hue, 1, BRIGHT)
np.write()

Step 4. 켜진 칸 수로 양을 나타내는 게이지 — 뒤 장(공기질·날씨)의 핵심 기법이에요.

예제 · 게이지 차오르기PYTHON
# 게이지처럼 켜진 칸 수 조절하기 (뒤의 공기질·날씨 LED의 기초!)
from machine import Pin
from neopixel import NeoPixel
import time

TIMING = (280, 515, 515, 745)
NUM = 10
np = NeoPixel(Pin(16), NUM, timing=TIMING)

def gauge(level, on_color=(0, 30, 0)):
    # level: 0~10, 켤 칸 수
    for i in range(NUM):
        np[i] = on_color if i < level else (0, 0, 0)
    np.write()

for n in range(0, NUM + 1):           # 0칸 → 10칸 차오르기
    gauge(n)
    time.sleep(0.2)
time.sleep(1)
gauge(0)                              # 모두 끄기

내 감정 표현하기 (이 장의 작품)

이제 배운 걸 모아 감정 무드등을 만들어요. 색은 ‘무슨 감정인지’, 움직임(숨쉬기·깜빡임·반짝임)은 ‘감정의 느낌·세기’를 나타냅니다. 이런 코드는 손으로 치지 말고, AI에게 아래처럼 설명해 만들면 돼요.

🙋 발문 — 색만으로 감정이 전달될까
“빨간불 하나만 보고 이 사람이 화난 건지, 신난 건지 알 수 있을까요? 움직임(느린 숨쉬기 vs 빠른 깜빡임)이 더해지면 뭐가 달라질까요?” — 답을 주지 말고, ‘같은 색·다른 움직임’ 두 가지를 직접 켜서 비교하게 하세요. 색=감정의 종류, 움직임=감정의 세기라는 이 장의 설계 원리를 학생이 스스로 발견하게 됩니다.
🤖① AI에게 이렇게 설명하세요 (그대로 복사)
라즈베리파이 피코에서 돌아가는 마이크로파이썬(MicroPython) 코드를 만들어줘. 열 칸짜리 LED 바로 내 기분을 표현하는 '감정 무드등'이야. - LED 바(WS2813)는 16번 핀에 연결했어. LED를 만들 때 타이밍 값 네 개(280, 515, 515, 745)를 꼭 지정해줘. 없으면 색이 깨져. - 밝기는 눈이 부시지 않게 낮게(최대 60 정도). - 색과 움직임을 조합해 기쁨·평온·화남·신남 네 가지 감정을 표현해줘. 예: 기쁨=따뜻한 노랑이 두근두근 숨쉬기, 평온=파랑이 천천히 숨쉬기, 화남=빨강 깜빡임, 신남=청록이 아무 칸에나 반짝. - 버튼은 없으니 코드 맨 아래 변수 하나만 바꾸면 감정을 고를 수 있게 해줘. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.

아래는 완성본이에요. 버튼이 없으니 코드 맨 아래 MOOD 한 줄만 바꿔 기분을 골라요.

② 전체 코드 · 감정 무드등 (main.py)PYTHON
# LED로 감정 표현하기 — 색과 움직임으로 기분을 나타내요
# 버튼이 없으니, 맨 아래 MOOD 한 줄만 바꿔서 내 기분을 골라요.
from machine import Pin
from neopixel import NeoPixel
import time, random

TIMING = (280, 515, 515, 745)   # WS2813 필수!
NUM = 10
np = NeoPixel(Pin(16), NUM, timing=TIMING)

def fill(c):
    for i in range(NUM):
        np[i] = c
    np.write()

def pulse(c, times=3, delay=0.02):     # 숨쉬듯 밝아졌다 어두워지기 (delay 작을수록 빠름)
    for _ in range(times):
        for b in list(range(0, 60, 4)) + list(range(60, 0, -4)):
            fill((c[0] * b // 60, c[1] * b // 60, c[2] * b // 60))
            time.sleep(delay)

def blink(c, times=6):          # 깜빡깜빡
    for _ in range(times):
        fill(c); time.sleep(0.15)
        fill((0, 0, 0)); time.sleep(0.15)

def sparkle(c, times=40):       # 반짝반짝 (랜덤 칸)
    for _ in range(times):
        fill((0, 0, 0))
        np[random.randint(0, NUM - 1)] = c
        np.write()
        time.sleep(0.05)

# 감정 프리셋: 색 + 움직임을 골라 함수로 묶었어요
def joy():     pulse((50, 40, 0), delay=0.012)   # 기쁨: 따뜻한 노랑, 두근두근(빠르게)
def calm():    pulse((0, 20, 40), delay=0.05)    # 평온: 파랑, 천천히 숨쉬기
def anger():   blink((60, 0, 0))      # 화남: 빨강 깜빡
def excited(): sparkle((0, 50, 30))   # 신남: 청록 반짝

MOODS = {"기쁨": joy, "평온": calm, "화남": anger, "신남": excited}

MOOD = "기쁨"        # ← 여기만 바꿔서 내 기분을 골라요! (기쁨/평온/화남/신남)

while True:
    MOODS[MOOD]()
    time.sleep(0.5)

나만의 감정을 추가해 봐요. 색((r,g,b))과 움직임(pulse/blink/sparkle)을 골라 함수 하나만 더 만들면 됩니다. 처음부터 다시 설명할 필요 없이, 같은 대화에서 ③ 개선 프롬프트로 이어 가면 돼요.

✨③ 프롬프트 개선 — 감정 추가 (이어서 복사)
방금 만든 감정 무드등을 이어서 개선해줘. - '슬픔'과 '설렘' 두 감정을 추가해줘. 슬픔은 파란색이 천천히 한 칸씩 흘러내리는 느낌, 설렘은 분홍색이 점점 빨라지며 반짝이는 느낌으로. - 밝기는 지금처럼 낮게 유지하고, LED 타이밍 값과 핀 번호도 그대로 둬. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.

자주 하는 실수
