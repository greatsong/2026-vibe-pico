CHAPTER 🗓 운영

20시간 연수 운영 계획 (4일 × 5시간)

본편 0~7장 + ML 확장판(소리·동작)을 4일 20시간에 담는 표준 진행안입니다. 하루 300분 기준이며, 블록 사이 10분 휴식을 끼워 운영하세요.

🎯 이 장을 마치면
  • 하루 단위 목표와 시간 배분을 한눈에 파악한다
  • 6장 ‘밤새 기록’을 차시 장치로 활용하는 법을 안다
  • 밀렸을 때 어디를 압축할지(버퍼) 미리 안다
💡 왜 배우나요?

전체 서사는 출력(LED) → 입력(센서) → 인터넷(받기·보내기) → 머신러닝 → 종합입니다. 설계의 축은 두 가지 — ① 매일 클리프행어로 끝낸다(2장 작품 예고, 6장 밤새 기록, IMU 예고), ② 6장 기록을 2일차 마지막에 두어 3일차 아침이 복습이 아니라 ‘데이터 개봉식’이 되게 한다.

한눈에 보기

1일차 · 첫 만남
세팅 → 첫 IoT(와이파이) → LED 기본기. Ch0~Ch2 전반
2일차 · 데이터
LED 작품 → 공기질(웹·LED) → 날씨 API → 시트 기록 시작하고 퇴근. Ch2 후반~Ch6
3일차 · 머신러닝
데이터 개봉식 → 소리 분류(INMP441) → 동작 인식(IMU) 전반
4일차 · 종합
동작 인식 완성 → 자유 프로젝트(기획·제작·발표)
🔑 전날 미리 확인 — 6장 밤새 기록의 성패
2일차 전까지 ① 교실 콘센트·USB 어댑터(휴대폰 충전기면 충분) ② 야간 와이파이 차단 여부를 확인하세요. 야간에 막히는 학교라면 6장을 3일차 오전으로 옮기고 ‘점심 2~3시간 기록’으로 계획을 바꿉니다 — 목적은 밤샘이 아니라 ‘내가 안 보는 시간의 데이터’입니다.

1일차 — 피코와 첫 만남 (300분)

시간내용비고
30분OT + 준비물 점검그로브 케이블(LED용) vs 암 점퍼 케이블(MQ-2용) 구분을 여기서 확실히. 데이터용 여분 USB 케이블 3~4개 준비
90분Ch0 준비하기 — Thonny·조립·펌웨어·첫 코드MQ-2 노란선→AO 확인 · 전원 스위치 5V. 케이블 불량이 최다 막힘
120분Ch1 와이파이 사각지대 찾기wifi_config.py 저장 습관 — 3·5·6장까지 계속 재사용. 강사 핫스팟이 가장 안전
60분Ch2 전반 — timing 개념 + 기본 점등·채우기·무지개‘timing 없으면 Ctrl+F 검색 → AI에 재요청’ 습관 심기
💡 밀렸을 때
Ch0이 밀리면(가장 흔한 시나리오) Ch2 전반을 통째로 2일차로 미루세요. 2일차의 Ch4를 30분으로 압축하면 흡수됩니다.

2일차 — 데이터의 날: 측정 → 표현 → 인터넷 → 기록 (300분)

시간내용비고
10분리캡 + 전날 미해결 트러블 일괄 정리
50분Ch2 후반 — 게이지 + 감정 무드등 작품·상호 공유첫 ‘내 작품’ 경험 — 공유 시간을 아끼지 말 것
80분Ch3 공기질 웹 대시보드여기서 정한 WARNING 값을 6장 조건부 서식에서 재사용
40분Ch4 공기질 LED 게이지결합 장이라 짧게 — ‘배운 걸 조합하면 새 작품’ 메시지
75분Ch5 강수확률 API×LED‘인터넷에서 받기’ — 다음 블록(보내기)의 발판
45분Ch6 공기질 기록 노트 — 구글 설정 → 피코 연결 → 기록 시작하고 퇴근URL 자동 반영 상자로 시간 단축. 시트에 줄이 쌓이는 걸 확인한 뒤 전원 꽂아 두고 마침. ‘내일 아침에 같이 열어 봐요’로 클리프행어
⚠️ 6장 45분 운영의 관건 — 구글 화면
구글 쪽 설정(15분)은 스크린에 띄워 한 단계씩 같이 가세요. ‘모든 사용자’ 배포·경고 화면 ‘고급’·개인 계정(학교 워크스페이스 ✗) 세 지점에서 손이 올라옵니다. 중간 점검(?value=99) 전원 통과를 확인한 뒤 피코 연결로 넘어가면 나머지는 순조롭습니다.

3일차 — 데이터 개봉식 + 머신러닝의 날 (300분)

시간내용비고
30분📊 데이터 개봉식 — 6장 ‘쌓인 데이터로 탐구하기’“어제 우리가 떠난 뒤 교실은?” — 차트·조건부 서식·MAX/MIN/AVERAGE → 결론 한 줄 쓰기(‘우리 교실은 __시에 환기’)
150분ML1 소리를 배우는 피코 — INMP441 + k-NN 소리 분류확장판의 심장. 자기가 고른 소리로 데이터 수집하는 시간을 넉넉히. 정규화·k·확신도 개념
120분ML2 동작 인식 전반 — IMU 개념 + 6축 읽기 + 물통 플립 데이터 수집 시작수집한 데이터로 내일 예측 — 두 번째 클리프행어
ℹ️ MP3(말하기) 챕터를 재개한다면
SD 카드가 준비되어 ML+ ‘피코가 말을 한다’를 살리는 경우, ML2 전반 120분 → 60분으로 줄이고 그 자리에 MP3 75분을 넣으세요(ML2 나머지는 4일차로). 듣기→생각→말하기 사이클이 완성되는 대신 4일차 자유 프로젝트가 20분쯤 줄어듭니다.

4일차 — 종합과 자유 프로젝트 (300분)

시간내용비고
15분리캡
75분ML2 완성 — 물통 플립 학습 → 성공 예측성공/실패 데이터를 조별로 모으면 자연스러운 협력 활동
40분자유 프로젝트 기획 — 7장 아이디어 + 부록 A 카탈로그‘일주일 공기질 리포트’ 같은 기록형 작품(6장 응용)도 선택지로. 주제 결정에 10분 이상 쓰지 않기
110분제작 — 바이브코딩LED·센서·API·ML·시트 기록 조합 자유. 순회하며 프롬프트 개선 코칭. 중간 30분쯤 ‘LED에 뭐라도 켜진 사람?’ 점검
60분발표·공유 + 정리발문: “AI에게 뭐라고 설명했나요?” — 프롬프트가 곧 설계도

설계 노트 (시간이 왜 이렇게 배분됐나)

Ch6 45분의 출처
2일차에서 리캡 5분 + Ch2 10분 + Ch3 10분 + Ch4 5분 + Ch5 15분을 압축해 확보. Ch5·Ch6은 둘 다 ‘피코가 인터넷과 대화’라 연달아 배우면 인지 부하가 오히려 줄어요.
MP3 보류의 여유
말하기 챕터 75분이 빠진 자리를 IMU 전반(3일차)에 배분 → 4일차 자유 프로젝트가 185분으로 늘었습니다.
버퍼
매일의 리캡과 Ch4(40분)가 사실상 버퍼. 최악의 경우 개봉식을 15분으로, Ch4를 30분으로 압축.
차시형(학교 수업) 변환
같은 내용을 정규 수업으로 옮기면 장당 2차시(100분)씩 한 학기 분량. 6장 밤새 기록은 ‘차시 사이 일주일’로 자연 확장되고, 7장 자유 프로젝트+기록 리포트는 수행평가와 연결됩니다.
