CHAPTER B

부록 · 심화: 센서 데이터를 구글 시트에 쌓기

피코가 잰 값을 구글 시트에 한 줄씩 자동으로 기록합니다. 며칠치 데이터를 모아 그래프·통계로 탐구할 수 있어요. (설치할 것 없이 바로 됩니다)

🎯 이 장을 마치면
  • Google Apps Script로 시트에 데이터를 받는 웹앱을 만들 수 있다
  • 피코에서 센서값을 HTTPS로 시트에 전송할 수 있다
  • 쌓인 데이터를 시트의 차트로 탐구할 수 있다
💡 왜 배우나요?

지금까지는 값을 LED·웹으로 ‘그 순간’만 봤어요. 하지만 시간에 따라 쌓아 두면 훨씬 강력해집니다 — 하루 공기질 변화, 며칠치 신호 추세, 일주일 데이터를 그래프로 볼 수 있죠. 구글 시트는 무료이고, Apps Script 웹앱을 거치면 피코가 복잡한 로그인 없이 URL 하나로 데이터를 보낼 수 있어요.

그림으로 보기 — 데이터가 어떻게 쌓일까

마치 엽서를 보내는 것과 같아요. 피코가 지금 잰 숫자를 엽서에 적어 ‘구글 시트’라는 우편함으로 보내면, 시트에 새 줄이 하나씩 차곡차곡 쌓입니다. 👇

1단계 · 구글 쪽 설정 (한 번만)

  1. 새 구글 시트 만들기주소창에 sheets.new를 입력하면 새 시트가 열려요. (구글 계정이 필요해요 — 로그인 안 돼 있으면 로그인 화면이 먼저 뜹니다.) 첫 행(1행)에 시각·값이라고 적어 둡니다.
  2. Apps Script 열기메뉴 확장 프로그램 → Apps Script를 누르면 코드 편집기가 새 탭으로 열려요.
  3. 코드 붙여넣기 → 저장편집기에 이미 적힌 function myFunction()…을 전부 선택(Ctrl+A·맥은 ⌘A)해 지우고, 아래 코드를 통째로 붙여넣으세요. 파일 이름은 Code.gs 그대로 두고 저장(💾).
Apps Script 코드 (Code.gs 에 붙여넣기)JAVASCRIPT
function doGet(e) {
  const sh = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sh.appendRow([new Date(), e.parameter.value]);   // [시각, 값] 한 줄 추가
  return ContentService.createTextOutput("OK");
}
  1. 웹 앱으로 배포 시작오른쪽 위 파란 배포 → 새 배포를 누르고, ‘유형 선택’ 옆 톱니바퀴(⚙️)를 눌러 웹 앱을 고릅니다.
  2. 권한 설정 후 배포실행: 나 · 액세스 권한: 모든 사용자로 두고 배포를 누르세요. (피코는 로그인을 못 하니 꼭 ‘모든 사용자’!)
  3. 권한 승인 (처음 한 번만)‘액세스 승인’ → 내 구글 계정 선택 → ‘확인되지 않은 앱’ 경고가 떠도 정상 → 왼쪽 아래 고급 → ‘…(으)로 이동’ → 허용.
  4. 웹 앱 주소 복사마지막에 나오는 ‘웹 앱 URL’(/exec로 끝나는 긴 주소)의 복사를 누르세요. (디플로이 ID가 아니라 URL이에요!) 다음 단계에서 그대로 붙여넣습니다.
💡 겁먹지 마세요 — ‘확인되지 않은 앱’ 경고
빨간/노란 경고 화면은 ‘구글이 아직 검토하지 않은 앱’이라는 뜻일 뿐이에요. 내가 방금 만든 스크립트라 안전합니다. 왼쪽 아래 ‘고급’ → ‘…(으)로 이동(안전하지 않음)’ → ‘허용’ 순서로 넘어가면 됩니다.
ℹ️ 나중에 코드를 고치면 — 새 버전으로 재배포
Apps Script 코드를 수정했다면 배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포로 다시 배포해야 반영됩니다. (주소는 그대로예요.)
🧯 예상 오류 — 시트가 안 쌓이면 십중팔구 배포 설정
이 부록 막힘의 최다 원인은 두 가지입니다. ① 배포할 때 액세스 권한을 ‘모든 사용자’로 안 바꾸고 기본값(나만)으로 둠 — 피코는 로그인을 못 하니 아무 오류 없이 조용히 실패합니다. ② 코드를 고친 뒤 ‘새 버전’ 재배포를 안 함 — 편집기에서 저장만 하면 옛 코드가 계속 돕니다. “시트에 안 쌓여요” 손이 올라오면 피코 코드를 보기 전에 배포 관리 화면부터 함께 여세요.

2단계 · 피코에 붙여넣고 실행

ℹ️ 먼저 — 와이파이 정보 파일 (wifi_config.py)
이 코드는 와이파이 정보를 wifi_config.py에서 불러옵니다. main.py와 같은 위치에 이 파일을 새로 만들고 두 줄만 적어 저장하세요.

WIFI_SSID = "우리_와이파이_이름"
WIFI_PASSWORD = "비밀번호"

(1장에서 이미 만들었다면 그대로 두면 돼요. 피코는 2.4GHz 와이파이만 됩니다.)

아래 코드를 펼쳐(▶) 복사해 Thonny에 붙여넣고, 위쪽의 WEB_APP_URL = "…" 줄에서 따옴표 안 주소 전체를 아까 복사한 주소로 바꾸세요. (양쪽 따옴표 " 는 지우지 말고 남겨 두세요.)

전체 코드 · 센서값 → 구글 시트 (main.py) · 61줄 · 펼쳐서 복사
전체 코드 · 센서값 → 구글 시트 (main.py)PYTHON
# 센서값을 구글 시트에 보내기 (설치할 것 없음)
import network, socket, ssl, time, gc
from machine import ADC, Pin
from wifi_config import WIFI_SSID as SSID, WIFI_PASSWORD as PASSWORD

# ↓ 이 따옴표 안 주소 전체를, 구글에서 복사한 웹 앱 주소(.../exec)로 바꾸세요
WEB_APP_URL = "https://script.google.com/macros/s/...여기에_주소_붙여넣기.../exec"
INTERVAL = 60                 # 몇 초마다 보낼지 (60 = 1분)
gas = ADC(Pin(26))           # 가스센서 (그로브 A0)

def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(SSID, PASSWORD)
    print("Wi-Fi 연결 중", end="")
    t = 20
    while not wlan.isconnected() and t > 0:
        print(".", end=""); time.sleep(0.5); t -= 1
    print("\nOK" if wlan.isconnected() else "\n실패")
    return wlan.isconnected()

def https_get(url):           # 전체 주소(https://...)를 받아 요청
    host, _, path = url[8:].partition("/")
    gc.collect()
    s = socket.socket()
    s.connect(socket.getaddrinfo(host, 443)[0][-1])
    try:
        ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
        ctx.verify_mode = ssl.CERT_NONE
        s = ctx.wrap_socket(s, server_hostname=host)
    except AttributeError:
        s = ssl.wrap_socket(s, server_hostname=host)
    s.write(("GET /%s HTTP/1.0\r\nHost: %s\r\nConnection: close\r\n\r\n"
             % (path, host)).encode())
    buf = b""
    while True:
        c = s.read(512)
        if not c:
            break
        buf += c
    s.close()
    return buf

def send(value):
    resp = https_get(WEB_APP_URL + "?value=" + str(value))
    head = resp.split(b"\r\n\r\n", 1)[0]
    if b" 302 " in head or b" 301 " in head:     # 구글이 다른 주소로 넘기면 따라가기
        for line in head.split(b"\r\n"):
            if line.lower().startswith(b"location:"):
                https_get(line.split(b":", 1)[1].strip().decode())
                break

if connect_wifi():
    while True:
        v = gas.read_u16()
        try:
            send(v)
            print("시트로 보냄:", v)
        except Exception as e:
            print("실패(잠시 뒤 다시 시도):", e)
        time.sleep(INTERVAL)

그리고 ▶ 실행하면 끝! (피코에 main.py로 저장하면 전원만 넣어도 자동 실행돼요. 실행·저장이 낯설면 0장을 참고하세요.) 이 코드는 가스센서(MQ-2) 기준이라, 다른 센서를 쓰면 코드에서 센서 읽는 줄만 바꾸면 됩니다.

🔑 둘은 ‘value’라는 이름으로 짝이에요
피코는 주소 뒤에 ?value=42처럼 값을 붙여 보내고, Apps Script(1단계 코드)는 그 value를 꺼내 시트 ‘값’ 칸에 적습니다. 양쪽 이름이 같아서 짝이 맞는 거예요.
💡 잘 되는지 확인하는 법
코드를 실행한 채 구글 시트를 열어 두세요. 1분마다 줄이 하나씩 스르륵 늘어나면 성공! Thonny 아래 셸(Shell) 칸에 시트로 보냄: 42 같은 메시지가 1분마다 찍혀도 잘 가는 거예요. 안 되면 아래 ‘자주 막히는 곳’을 보세요.
ℹ️ 왜 딱 60초마다 안 와요?
INTERVAL은 ‘쉬는 시간’만 정해요. 그런데 한 바퀴에는 쉬는 시간 + 인터넷으로 보내는 시간이 같이 들어가요. 인터넷 전송이 몇 초 더 걸리고 그 시간도 매번 조금씩 달라서, 실제 간격은 설정값보다 살짝 길고 들쭉날쭉합니다. ‘정확한 초’보다 ‘꾸준히 기록’이 목적이라 괜찮아요. (정확히 맞추고 싶으면 보낸 데 걸린 시간을 빼고 남은 만큼만 쉬게 하면 돼요.)

쌓인 데이터로 탐구하기

시트에 줄이 쌓이면, 값 열을 선택하고 삽입 → 차트로 추세 그래프를 바로 그릴 수 있어요. ‘하루 중 공기질이 가장 나쁜 시간’, ‘환기 전후 변화’, ‘요일별 비교’ 같은 탐구로 이어집니다.

자주 막히는 곳

❌ 시트에 아무것도 안 쌓임
원인웹앱 액세스 권한이 ‘모든 사용자’가 아님.
해결배포를 모든 사용자로 다시 하세요. 코드 수정 후엔 배포 관리 → 편집 → 새 버전으로 재배포해야 반영됩니다.
❌ ImportError: no module named 'wifi_config'
원인wifi_config.py가 피코에 없음.
해결위 2단계 안내대로 wifi_config.py를 main.py와 같은 위치에 만들고 와이파이 두 줄(WIFI_SSID, WIFI_PASSWORD)을 적으세요.
❌ 셸에 ‘실패’라고 떠요
원인잠깐 인터넷이 끊겼을 때 그래요.
해결한두 번은 괜찮아요 — 다음 차례에 다시 보냅니다. 계속 그러면 보내는 간격(INTERVAL)을 늘려 보세요.
❌ 시각이 한국시간과 다름
원인Apps Script 프로젝트 시간대가 기본(미국).
해결Apps Script 프로젝트 설정(⚙️) → 시간대 → (GMT+09:00) 서울로 바꾸세요.
❌ 문자열 값이 깨짐
원인공백·특수문자를 URL에 그대로 넣음.
해결숫자 센서값은 문제없어요. 문자열은 공백 등을 %20처럼 URL 인코딩하거나 단순 텍스트/숫자만 보내세요.

바이브코딩 프롬프트

🤖AI에게 이렇게 설명하세요 (그대로 복사)
라즈베리파이 피코 2 W에서 돌아가는 마이크로파이썬(MicroPython) 코드를 만들어줘. 센서값을 구글 시트에 자동 기록하는 장치야. - 가스센서(MQ-2)를 아날로그 입력인 26번 핀으로 읽어, 60초마다 구글 시트에 한 줄씩 기록하고 싶어. - 기록 방법: 구글 앱스 스크립트(Apps Script)로 배포한 웹 앱 주소('/exec'로 끝나는 전체 주소) 뒤에 '?value=측정값'을 붙여 요청을 보내는 방식이야. - 외부 라이브러리는 설치하지 말고 피코 기본 내장 기능(socket, ssl)만 써. 보안 인증서 확인은 건너뛰어도 되고, 구글이 다른 주소로 한 번 건너뛰게 하면(리다이렉트) 그것까지 따라가서 마무리해줘. - 와이파이 정보는 설정 파일(wifi_config.py)에서 불러오고, 웹 앱 주소와 보내는 주기는 코드 맨 위에 둬. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.

스스로 점검하기

피코가 구글 로그인 없이 시트에 쓸 수 있는 이유는?
Apps Script 웹앱을 ‘모든 사용자’로 배포해, URL만 알면 누구나(피코도) 호출할 수 있게 했기 때문입니다.
보내는 간격을 바꾸려면?
코드 맨 위 INTERVAL 숫자를 바꾸면 됩니다. 60이면 1분마다, 300이면 5분마다 보내요.
쌓인 데이터로 무엇을 할 수 있나요?
