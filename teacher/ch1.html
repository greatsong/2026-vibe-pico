CHAPTER 01

와이파이 사각지대 찾기

피코를 들고 교실을 돌아다니며 와이파이 신호 세기(RSSI)를 측정해, 신호가 약한 ‘사각지대’를 찾고 스마트폰으로 실시간 확인합니다. 첫 IoT 작품이에요.

🎯 이 장을 마치면
  • 피코를 와이파이(STA 모드)에 연결할 수 있다
  • 신호 세기(RSSI)가 무엇이고 어떻게 읽는지 안다
  • 측정하며 돌아다녀 신호가 약한 ‘사각지대’를 찾을 수 있다
  • 피코를 작은 웹서버로 만들어 브라우저에서 데이터를 본다
  • ‘피코는 /data로 값만 주고, 그래프는 브라우저가 그린다’는 구조를 이해한다
💡 왜 배우나요?

교실·집 어디나 와이파이가 똑같이 잘 터지진 않아요. 피코로 신호 세기(RSSI)를 재면서 돌아다니면 어디가 약한지(사각지대)를 찾을 수 있어요. 게다가 피코가 웹서버가 되면 같은 와이파이의 누구나 스마트폰으로 실시간 값을 함께 볼 수 있죠. 이 장에서 익히는 ‘피코=서버, 브라우저=화면’ 구조는 뒤의 공기질·날씨 대시보드에서도 똑같이 재사용됩니다.

핵심 개념

STA 모드
피코가 집/학교 와이파이에 접속하는 모드. network.WLAN(network.STA_IF)
RSSI
신호 세기. 단위는 dBm이고 음수예요. -50처럼 0에 가까울수록 강하고, -80처럼 작을수록 약합니다.
소켓 웹서버
포트 80에서 브라우저의 접속을 기다리다가, 요청이 오면 HTML이나 데이터를 돌려주는 작은 서버.
/data 폴링
브라우저가 1초마다 /data를 불러 최신 값을 받고, Chart.js로 그래프를 갱신하는 방식.
🔬 더 알아보기 — RSSI는 왜 -50, -80처럼 ‘음수’일까? (dBm과 데시벨)
RSSI(Received Signal Strength Indicator)의 단위 dBm은 ‘1밀리와트(mW)에 견준 신호 세기를 데시벨로 나타낸 값’이에요. 정의상 0 dBm = 1 mW입니다.

와이파이 신호가 안테나에 도달할 때의 전력은 1 mW보다 훨씬 작아서(보통 1mW의 수만분의 1 ~ 1억분의 1 수준), 로그(데시벨)로 바꾸면 음수가 됩니다. 그래서 값이 항상 마이너스예요.
· -30 dBm ≈ 아주 강함(공유기 바로 옆)
· -67 dBm ≈ 영상통화도 무난
· -80 dBm ≈ 약함, 끊길 수 있음

데시벨은 로그 스케일이라, 10 dB 차이가 전력 10배 차이예요. 즉 -60에서 -70으로 떨어지면 신호 전력이 1/10로 준 겁니다. 숫자 차이는 작아 보여도 체감 차이가 큰 이유죠.
🙋 발문 — 개념을 몸으로 먼저
“신호 세기가 -50인 자리와 -80인 자리, 어디가 더 잘 터질까요? 왜 0이 아니라 음수로 잴까요?” — 답을 주지 말고 스캔(Step 1) 결과를 보며 스스로 확인하게 하세요. ‘공유기에서 멀어지면 어떻게 될까?’로 사각지대 활동을 예고하면 동기부여가 됩니다.
🎙️ 진행 팁 — 네트워크는 강사 핫스팟이 제일 안전
학교망은 기기 간 통신(피코↔폰)이 막힌 경우가 많습니다. 강사 휴대폰 핫스팟(2.4GHz)을 하나 열어 두고, 막히는 학생은 그리로 옮기게 하세요. SSID·비밀번호를 칠판에 크게 적어 두면 wifi_config.py 오타 질문이 크게 줄어듭니다.

# 주변에 어떤 와이파이가 있는지 스캔해 봅니다
import network

wlan = network.WLAN(network.STA_IF)   # STA = 와이파이에 '접속하는' 모드
wlan.active(True)

for net in wlan.scan():
    ssid = net[0].decode()            # 와이파이 이름
    rssi = net[3]                     # 신호 세기 (dBm, 0에 가까울수록 강함)
    print("%-22s  %d dBm" % (ssid, rssi))

wlan = network.WLAN(network.STA_IF)


def connect_wifi():
    wlan.active(True)
    wlan.connect(SSID, PASSWORD)
    print("Wi-Fi 연결 중", end="")
    timeout = 20
    while not wlan.isconnected() and timeout > 0:
        print(".", end="")
        time.sleep(0.5)
        timeout -= 1
    if wlan.isconnected():
        ip = wlan.ifconfig()[0]
        print("\n✅ 연결 완료!  →  http://%s" % ip)
        return ip
    print("\n❌ Wi-Fi 연결 실패")
    return None

def send_response(conn, content_type, body):
    header = (
        "HTTP/1.1 200 OK\r\n"
        "Content-Type: %s\r\n"
        "Content-Length: %d\r\n"
        "Connection: close\r\n"
        "\r\n"
    ) % (content_type, len(body))
    conn.sendall(header.encode() + body)


def run_server():
    addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
    srv = socket.socket()
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind(addr)
    srv.listen(3)
    print("서버 대기 중... (브라우저로 위 주소에 접속하세요)")
    while True:
        conn, _ = srv.accept()
        try:
            req = conn.recv(512).decode("utf-8", "ignore")
            if "GET /data" in req:
                value = wlan.status("rssi")
                body = json.dumps({"value": value}).encode()
                send_response(conn, "application/json", body)
            else:
                send_response(conn, "text/html; charset=utf-8", HTML)
        except Exception as e:
            code = e.args[0] if e.args else None
            tip = {104: "브라우저가 연결을 먼저 끊음 (정상, 무시 OK)",
                   32:  "응답 도중 연결이 끊김 (정상)",
                   110: "응답 대기 시간 초과",
                   11:  "데이터가 아직 안 옴 (일시적)"}.get(code)
            print("요청 처리:", ("[%s] %s" % (code, tip)) if tip else ("오류 " + str(e)))
        finally:
            conn.close()


ip = connect_wifi()
if ip:

Step 5. 여기서 바이브코딩으로 마무리해 봐요. 숫자만 보여 주는 대신, 신호 세기에 따라 재미있게 반응하도록 AI에게 이어서 설명합니다. ①→② 흐름에 이어 붙이는 ③ 개선 프롬프트예요.

✨③ 프롬프트 개선 — 신호 세기에 반응하는 화면 (이어서 복사)
방금 만든 신호 세기 대시보드를 이어서 개선해줘. 신호 세기에 따라 화면이 재미있게 반응하면 좋겠어. - 강할 때(약 -60dBm 이상): 초록색 배경에 '신호 최고예요! 😄' 같은 축하 문구를 살짝 반짝이게. - 보통(-60 ~ -78dBm): 노란색에 '쓸 만해요'. - 약할 때(약 -78dBm 이하): 빨간색으로 '⚠️ 신호 약함, 끊길 수 있어요' 경고를 크게 띄우고 화면이 살짝 흔들리게. - 피코의 16번 핀에 열 칸짜리 LED 바(WS2813)가 연결돼 있다면 같은 상태를 LED 색으로도 보여줘. 강함=초록, 보통=노랑, 약함=빨강 깜빡임. - 이 LED는 만들 때 타이밍 값 네 개(280, 515, 515, 745)를 꼭 지정해야 색이 안 깨져. 이 값과 핀 번호는 그대로 유지하고, 밝기는 눈부시지 않게 낮게(채널당 최대 60 정도)로 해줘. - 복사해서 바로 돌아가는 완결형 main.py 전체를 한 번에 줘.
💡 바이브코딩 팁
받은 코드를 올리기 전에 ① 신호 기준값(-60·-78 등)이 우리 환경에 맞는지 ② LED를 함께 쓴다면 timing 인자가 들어 있는지 확인하세요. (LED와 timing은 2장에서 자세히 배워요 — 지금은 화면만으로도 충분합니다.) 기준값은 직접 돌아다니며 ‘강한 곳/약한 곳’ RSSI를 보고 조정하면 더 정확해요.
ℹ️ 들고 다니려면 — 전원 준비
사각지대를 찾으려면 피코를 들고 돌아다녀야 해요. 노트북에 USB로 연결한 채 움직이거나, 보조배터리(파워뱅크)에 USB로 연결하면 선 없이 교실 곳곳의 신호를 잴 수 있어요. 측정 위치를 바꿀 때마다 몇 초 기다렸다가 값을 읽으세요.

자주 하는 실수

❌ 계속 연결 중... 에서 멈춤
원인5GHz 와이파이이거나 비밀번호 오타.
해결피코는 2.4GHz 와이파이만 됩니다. 5GHz 전용이면 안 돼요. SSID/비번 대소문자도 정확히 확인하세요.
❌ 브라우저에서 주소가 안 열림
원인스마트폰이 피코와 다른 와이파이에 있음.
해결스마트폰을 피코와 같은 와이파이에 연결하세요. 학교망은 기기 간 통신이 막힌 경우도 있어, 휴대폰 핫스팟이 가장 확실합니다.
❌ RSSI가 0 또는 이상한 값
원인연결 전에 status를 읽음.
해결wlan.isconnected()가 참이 된 뒤에 읽어야 합니다. (위 코드는 이미 연결 후 읽습니다)

스스로 점검하기

RSSI가 -50과 -80 중 어느 쪽이 더 좋은 신호인가요?
-50입니다. 0에 가까울수록 강한 신호예요.
그래프는 피코가 그리나요, 브라우저가 그리나요?
브라우저가 그립니다. 피코는 /data로 숫자만 보내고, Chart.js가 화면에 그려요. 그래서 피코의 부담이 적습니다.
wifi_config.py를 따로 두는 이유는?
비밀번호를 코드 본문과 분리해 관리하기 쉽고, 여러 코드가 같은 설정을 재사용할 수 있어서요.
