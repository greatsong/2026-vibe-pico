CHAPTER A

부록 · 오픈 API 한눈에 보기

프로젝트에 쓸 만한 과목별 오픈 API 카탈로그예요. 각 API가 어떤 데이터를 주고 무엇을 탐구할 수 있는지 보고, 바로 살아 있는 대시보드로 들어가 보세요.

💡 왜 배우나요?

5장에서 API로 데이터를 받아 표현하는 흐름을 익혔죠. 이 부록은 과목별 오픈 API를 한눈에 정리한 카탈로그예요 — 각 API가 어떤 데이터를 주고 어떤 탐구를 할 수 있는지, 그리고 브라우저에서 바로 그려 보는 라이브 대시보드로 연결됩니다. 피코로 직접 받아오려면 5장 ‘날씨 시계’에서 쓴 socket+ssl 방식을 그대로 응용하면 돼요. (API는 2026년 기준 응답 확인)

이 부록 쓰는 법

🔑 🌐 라이브 대시보드로 데이터를 ‘직접’ 만나 보기
각 API 카드의 ‘라이브 대시보드 열기’를 누르면, 브라우저에서 지금 데이터를 받아 지도·그래프로 그려 주는 페이지가 열려요(설치·피코 없이 클릭만). 위치·물질·종을 바꿔 가며 탐구하고, 페이지마다 ‘🔎 탐구 질문’도 있습니다.
🔗 오픈 API 라이브 대시보드 갤러리 열기 (10종 · 5장 날씨 포함)
ℹ️ 국내 적용 여부 한눈에
🇰🇷 국내 OK(일출몰·생물) · 🌍 전 지구라 국내도 포함(대기질·ISS) · 🌐 국적 무관(화학·천문) · 🌎 해외 위주(지진은 국내 드묾 → 기상청 권장). 국내 공식 데이터는 공공데이터포털(키 필요)을 쓰세요.
🎙️ 진행 팁 — 교과 연계로 소개하기
갤러리 10종을 하나씩 다 보여 주기보다, “내 과목과 닿는 API 하나를 골라 10분 탐구해 보세요”라고 던지는 편이 낫습니다. 지구과학=지진·일출몰, 화학=PubChem, 생물=GBIF, 환경=대기질·CO₂, 물리·에너지=ISS·태양광 — 이렇게 과목별 짝을 한 줄씩만 안내하고, 마무리에 “이 데이터로 수업에서 뭘 시켜 보고 싶은지” 한 사람씩 말하게 하면 자기 수업과 연결된 채 끝납니다.
