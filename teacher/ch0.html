CHAPTER 00

준비하기

Thonny 설치부터 피코·그로브 쉴드·센서 조립, 펌웨어 설치, 첫 코드까지 — 여기만 끝내면 모든 장을 따라올 수 있어요.

🎯 이 장을 마치면
  • Thonny(코드 편집기)를 설치하고 실행할 수 있다
  • 피코 2 WH에 그로브 쉴드와 센서를 바르게 연결할 수 있다
  • MicroPython 펌웨어를 설치하고 Thonny와 피코를 연결할 수 있다
  • 보드 위 LED를 깜빡이는 첫 코드를 실행할 수 있다
💡 왜 배우나요?

피코는 손바닥만 한 작은 컴퓨터예요. 다만 처음 한 번은 ① 코드를 쓸 도구(Thonny) 설치 → ② 하드웨어 조립 → ③ 피코에 ‘운영체제’ 격인 펌웨어 설치 → ④ 도구와 피코 연결 순서를 거쳐야 합니다. 이 4단계만 통과하면, 다음 장부터는 코드를 복사해 붙여넣고 ▶ 버튼만 누르면 돼요.

0.1 · 준비물 확인

책상 위에 아래 물건이 모두 있는지 먼저 확인하세요.

  • Raspberry Pi Pico 2 WH (핀 헤더가 납땜된 버전)
  • 그로브 쉴드 (Grove Shield for Pi Pico v1.0)
  • WS2813 RGB LED 바 (10개짜리) + 그로브 케이블 1개
  • MQ-2 가스센서 모듈 — 그로브 모듈이 아니에요! 핀이 4개 나온 핀헤더형
  • 그로브 암(Female) 점퍼 케이블 1개 — 한쪽은 그로브 커넥터, 반대쪽은 까만 암 단자 4가닥 (MQ-2 연결용)
  • 데이터 전송이 되는 Micro 5핀 USB 케이블 (충전 전용 케이블 ✗)
  • Windows 또는 macOS 컴퓨터
⚠️ USB 케이블 주의
세상에는 ‘충전만 되는’ USB 케이블이 의외로 많아요. 피코가 컴퓨터에 인식되지 않으면, 가장 먼저 다른 케이블로 바꿔 보세요. 이게 제일 흔한 막힘 지점이에요.
🎙️ 진행 멘트 — 준비물 점검 (2분)
“책상 위 준비물이 다 있는지 옆 사람과 서로 확인해 주세요. 하나라도 없으면 지금 손 들어 주세요.” — 케이블 불량이 가장 흔하니 데이터용 여분 케이블을 3~4개 미리 챙겨 두면 진행이 매끄럽습니다. 그리고 그로브 케이블(LED용)과 암 점퍼 케이블(MQ-2용)을 미리 구분하게 해 주세요 — 여기서 헷갈리면 조립 단계가 밀립니다.

0.2 · Thonny 설치 (코드 편집기)

Thonny는 우리가 쓴 코드를 피코에게 전달하고, 피코가 보내는 메시지를 받아 보여 주는 창구예요. 파이썬 입문용으로 가장 쉽고, 피코를 기본 지원합니다.

🔗 thonny.org — Thonny 내려받기
  1. thonny.org 접속위 버튼을 눌러 공식 사이트로 갑니다.
  2. 내 운영체제용 설치파일 받기오른쪽 위에서 Windows 또는 macOS에 맞는 파일을 내려받습니다.
  3. 설치 실행받은 파일을 더블클릭해 안내대로 설치합니다. (옵션은 기본값 그대로 두면 됩니다)
  4. Thonny 실행설치가 끝나면 Thonny를 엽니다. 위에 코드 쓰는 칸, 아래에 Shell(셸) 칸이 보이면 성공이에요.
❌ 설치 파일이 백신/보안 경고로 막힘
원인다운로드 직후 일부 백신이 과민 반응합니다.
해결공식 사이트(thonny.org)에서 받았다면 안전합니다. ‘허용’ 또는 ‘추가 정보 → 실행’을 선택하세요.

0.3 · 하드웨어 조립

그로브 베이스 쉴드는 피코 위에 ‘덮어 끼우는’ 확장 보드예요. 센서를 납땜 없이 케이블로 톡 꽂을 수 있게 해 줍니다. 아래 그림처럼 연결합니다.

  1. 피코를 그로브 쉴드에 꽂기핀 방향을 맞춰 피코를 쉴드에 끝까지 눌러 끼웁니다. USB 단자가 쉴드 바깥쪽을 향하도록 방향을 확인하세요. 한 줄이라도 핀이 어긋나면 안 됩니다.
  2. LED 바 → D16 포트WS2813 LED 바의 그로브 케이블을 쉴드의 D16 포트에 꽂습니다. (코드에서는 GP16)
  3. MQ-2 센서 → A0 포트 (암 점퍼 케이블)MQ-2는 그로브 모듈이 아니라서 케이블이 달라요. 그로브 암 점퍼 케이블의 그로브 쪽을 쉴드의 A0 포트에 꽂고, 반대쪽 암 단자를 센서에 새겨진 핀 글자를 보며 하나씩: 빨강 → VCC · 검정 → GND · 노랑 → 센서의 AO 핀. 흰선과 센서의 DO 핀은 아무 데도 안 꽂고 비워 둡니다. 여기서 AO는 쉴드가 아니라 센서 쪽 핀 이름이에요 — 쉴드에는 그로브 커넥터만 통째로 꽂으면 끝. (코드에서는 GP26 / ADC0)
  4. USB로 컴퓨터에 연결USB 케이블로 피코와 컴퓨터를 연결합니다. (펌웨어를 처음 설치할 때는 0.4의 BOOTSEL 순서를 따르세요)
⚠️ 꽂는 위치를 헷갈리지 마세요
D16(디지털)과 A0(아날로그)는 쓰임이 다릅니다. LED는 D16, 가스센서는 A0. 반대로 꽂으면 값이 이상하거나 LED가 안 켜져요.
⚠️ MQ-2의 AO와 DO — 노란선은 반드시 센서의 AO 핀에
MQ-2 핀은 VCC · GND · DO · AO 네 개예요. 우리가 읽는 건 AO(아날로그 출력) — 노란선이 DO에 꽂히면 값이 0이나 65535 근처에 붙어 움직이지 않습니다. 3장에서 값이 이상하면 제일 먼저 노란선이 센서의 AO 핀에 있는지 보세요. 그리고 이름이 닮아 정말 헷갈리기 쉬운데 — 쉴드의 A0(에이·제로)는 그로브 케이블을 통째로 꽂는 포트이고, 센서의 AO(에이·오)는 노란선 한 가닥을 꽂는 핀입니다. 노란선이 갈 곳은 쉴드가 아니라 센서예요. (센서 보드의 파란 네모(가변저항)는 DO 감도 조절용이라 우리 실습과는 무관해요.)
⚠️ 쉴드 모서리의 전원 스위치는 5V에
그로브 쉴드에는 포트 전원을 고르는 3V3 ↔ 5V 스위치가 있어요. 이 교재의 부품은 5V 쪽에 두면 모두 잘 동작합니다. LED는 양쪽 다 되지만, ML 확장판에서 쓰는 MP3 모듈은 5V가 아니면 부팅을 못 해요. (아날로그 포트 A0~A2는 스위치와 상관없이 항상 3.3V라 가스센서는 어느 쪽이든 괜찮습니다.)

0.4 · MicroPython 펌웨어 설치

갓 산 피코에는 아직 파이썬을 실행할 ‘속살’이 없어요. MicroPython 펌웨어를 한 번 설치하면, 그때부터 피코가 파이썬 코드를 알아듣습니다. (처음 한 번만 하면 됩니다)

🔌 처음 한 번만 — 펌웨어 설치

MicroPython 펌웨어 다운로드

Raspberry Pi Pico 2 W / WH 전용 · MicroPython v1.28.0 · UF2 1.64 MB

⬇  펌웨어 내려받기 (.uf2)
이렇게 설치해요 — 드래그 한 번이면 끝
  1. BOOTSEL 버튼을 누른 채 피코를 USB 케이블로 컴퓨터에 연결합니다. (순서 중요! 버튼 먼저 누르고 꽂기)
  2. 컴퓨터에 RP2350 이라는 USB 드라이브가 나타나면 버튼에서 손을 뗍니다. (Pico 2 계열. 구형 Pico는 RPI-RP2)
  3. 위 버튼으로 받은 .uf2 파일을 RP2350 드라이브로 복사(드래그)합니다.
  4. 피코가 자동으로 재부팅되며 설치 완료 — 이제 Thonny에서 코드를 올릴 수 있어요.

⚠️ 이 파일은 Pico 2 W (WH) 전용입니다. 다른 보드라면 MicroPython 공식 다운로드 페이지에서 맞는 펌웨어를 받으세요. · Thonny의 ‘Install MicroPython…’ 메뉴로 설치해도 됩니다.

🔬 더 알아보기 — 펌웨어? MicroPython? BOOTSEL? — 용어 정리
펌웨어(firmware)는 어떤 기기를 켰을 때 가장 먼저 돌아가는 ‘기본 소프트웨어’예요. 컴퓨터의 운영체제(윈도우·macOS)에 해당하는, 피코의 속살이라고 보면 됩니다.

MicroPython은 피코 같은 작은 컴퓨터(마이크로컨트롤러)에서 돌아가도록 만든 파이썬이에요. 이 펌웨어를 설치하면, 그때부터 피코가 우리가 쓴 파이썬 코드를 알아듣습니다. (C/C++로도 쓸 수 있지만, 파이썬이 가장 쉬워요.)

BOOTSEL 버튼은 피코를 ‘펌웨어를 새로 받을 준비(부트로더) 모드’로 켜는 버튼이에요. 이 버튼을 누른 채 USB를 꽂으면 컴퓨터에 USB 드라이브처럼 나타나고, 거기에 .uf2 파일을 끌어다 놓으면 설치됩니다.

.uf2는 이런 보드에 드래그&드롭으로 펌웨어를 넣도록 만든 파일 형식(USB Flashing Format)입니다.
❌ RP2350 드라이브가 안 나타남
원인BOOTSEL 버튼을 누르지 않고 꽂았거나, 충전 전용 케이블입니다.
해결케이블을 뽑고 → BOOTSEL 버튼을 누른 채 다시 꽂으세요. 그래도 안 되면 데이터용 케이블로 교체합니다.
🧯 예상 오류 — 펌웨어 단계에서 반드시 나오는 것
매 기수 2~3명은 BOOTSEL을 안 누르고 꽂거나, 드라이브가 뜨기 전에 손을 뗍니다. ‘버튼 먼저, 꽂는 건 나중’을 두 번 외치고 시작하세요. 이미 MicroPython이 깔린 피코는 드라이브가 안 뜨는 게 정상이니 ‘내 것만 안 떠요’ 질문에는 셸 연결(0.5)로 바로 넘어가면 됩니다.

# 셸(아래쪽 Shell 창)에 한 줄씩 입력해 보세요

안녕, 피코!가 셸에 찍히면, 컴퓨터와 피코가 대화에 성공한 거예요. 🎉 이제 보드 위 작은 LED를 깜빡여 봅시다.

이번엔 여러 줄 코드라, 셸이 아니라 위쪽 편집기 칸에 붙여넣고 실행해요.

보드 LED 깜빡이기 (편집기에 쓰고 ▶ 실행)PYTHON
from machine import Pin    # 핀 제어 도구
import time               # 시간(대기) 도구

led = Pin("LED", Pin.OUT)  # 피코 보드 위의 작은 LED

while True:               # 아래를 계속 반복
    led.value(1)          # 켜기
    time.sleep(0.5)       # 0.5초 대기
    led.value(0)          # 끄기
    time.sleep(0.5)
🔑 버튼 3개만 기억하세요 — ▶ 실행 · ⏹ 정지 · 💾 저장
① ▶ 실행(Run) — 편집기에 쓴 코드를 피코에서 돌립니다.
② ⏹ 정지(Stop) — while True처럼 계속 도는 코드를 멈춰요. 코드를 고쳐 다시 실행할 땐 먼저 ⏹로 멈춘 뒤 ▶를 누르세요(안 멈추면 ‘사용 중’이라 새로 안 돌아요).
③ 💾 저장 — 저장하면 ‘This computer(내 컴퓨터)’와 ‘Raspberry Pi Pico’ 중 어디에 저장할지 물어봐요. 꼭 Raspberry Pi Pico를 고르고 파일 이름은 main.py로 하세요. (그래야 전원만 넣어도 자동 실행되고, 뒤 장의 코드들이 서로(예: wifi_config.py)를 찾을 수 있어요.)

❌ 코드를 멈출 수 없음 (무한 반복)

Thonny에서 셸(Shell) 칸은 무슨 역할을 하나요?
코드를 한 줄씩 바로 실행해 보고, 피코가 print로 보낸 메시지를 보여 주는 ‘대화창’입니다.
펌웨어는 매번 설치해야 하나요?
아니요. 처음 한 번만 설치하면 계속 유지됩니다.
보드 LED를 코드에서 어떻게 가리켰나요?
Pin("LED", Pin.OUT) — 피코 보드에 내장된 LED를 출력 모드로 잡았습니다.
