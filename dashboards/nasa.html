오늘의 천문사진 (NASA)

천문🌐 국적 무관 · 키 필요

📋 어떤 데이터인가요?

NASA가 1995년부터 매일 한 장씩 골라 올리는 우주 사진과 천문학자의 설명(APOD). 성운, 은하, 행성… 오늘은 어떤 우주가 기다리고 있을까요?

무엇매일 바뀌는 천문 사진·설명 APOD (NASA)
API 키필요 — DEMO_KEY로 체험, api.nasa.gov에서 무료 발급
요청 예api.nasa.gov/planetary/apod?api_key=DEMO_KEY
주의DEMO_KEY는 시간당 호출 제한 → 안 되면 잠시 후/내 키로
