🐍 API 핵심 코드 — 복사해 내 프로젝트·AI에 응용

이 데이터를 받아오는 핵심만 추린 파이썬 코드예요(requests 사용). Streamlit 앱에 바로 쓰거나, 복사해서 AI(Claude 등)에게 “이 데이터로 ___ 만들어 줘”처럼 넘기면 됩니다.

📦 Streamlit Cloud에 배포한다면 requirements.txt에 requests를 한 줄 적어 주세요 (없으면 ModuleNotFoundError).

💻 파이썬 코드 보기 · 복사
나라별 CO₂·에너지 · Python (requests)
import requests

country = "KOR"  # 나라 코드 (KOR, USA, JPN ...)
indicator = "EN.GHG.CO2.PC.CE.AR5"  # 1인당 CO₂ 배출량(톤)

url = f"https://api.worldbank.org/v2/country/{country}/indicator/{indicator}"
arr = requests.get(url, params={"format": "json", "per_page": 5, "mrnev": 1}).json()

latest = arr[1][0]            # 응답은 [메타데이터, 데이터배열] 구조
co2 = latest["value"]         # 1인당 CO₂ 배출량(t)
year = latest["date"]         # 연도
print(year, co2)

🔧 공통 조건 — 아래 모든 프롬프트에 자동 포함 (펼쳐 보기)
공통 조건 · 피코·와이파이·LED
[공통 조건]
- 라즈베리파이 피코 2 W(MicroPython)에서 도는 완결형 main.py로 만들어 줘.
- 인터넷 접속은 외부 라이브러리 없이 피코 기본 내장 socket+ssl만 사용(requests 설치 금지). https는 인증서 검증 생략(CERT_NONE).
- 와이파이는 wifi_config.py 파일에 WIFI_SSID, WIFI_PASSWORD 두 변수로 저장해 두고 거기서 불러와.
- WS2813 LED 10개는 GP16에 연결, NeoPixel을 timing=(280,515,515,745)로 생성(없으면 색 깨짐), 밝기는 낮게(최대 60 정도).
- 응답이 크면 필요한 항목만 받아 메모리를 아끼고, 무한 루프엔 sleep으로 쉬어 줘.
나라별 CO₂ → LED 게이지
[API] World Bank(키 불필요): GET https://api.worldbank.org/v2/country/KOR/indicator/EN.GHG.CO2.PC.CE.AR5?format=json&per_page=5&mrnev=1 → 응답의 두 번째 배열 [0].value가 1인당 CO₂ 배출량(t).
[만들 것] 한 나라의 1인당 CO₂ 배출량을 받아 LED 게이지로(0~20t → 0~10칸), 세계 평균(약 4.5t)보다 높으면 빨강·낮으면 초록.
[설정] 나라 코드(KOR 등)는 코드 위.
