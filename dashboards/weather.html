🐍 API 핵심 코드 — 복사해 내 프로젝트·AI에 응용

이 데이터를 받아오는 핵심만 추린 파이썬 코드예요(requests 사용). Streamlit 앱에 바로 쓰거나, 복사해서 AI(Claude 등)에게 “이 데이터로 ___ 만들어 줘”처럼 넘기면 됩니다.

📦 Streamlit Cloud에 배포한다면 requirements.txt에 requests를 한 줄 적어 주세요 (없으면 ModuleNotFoundError).

💻 파이썬 코드 보기 · 복사
오늘의 날씨 · Python (requests)
import requests

LAT, LON = 37.5665, 126.9780  # 서울 (위도, 경도만 바꾸면 어디든)

data = requests.get("https://api.open-meteo.com/v1/forecast", params={
    "latitude": LAT, "longitude": LON,
    "hourly": "precipitation_probability",  # 시간별 강수확률
    "timezone": "Asia/Seoul", "forecast_days": 1,
}).json()

probs = data["hourly"]["precipitation_probability"]  # 0~23시 강수확률(%) 24개
print(probs)

🔧 공통 조건 — 아래 모든 프롬프트에 자동 포함 (펼쳐 보기)
공통 조건 · 피코·와이파이·LED
[공통 조건]
- 라즈베리파이 피코 2 W(MicroPython)에서 도는 완결형 main.py로 만들어 줘.
- 인터넷 접속은 외부 라이브러리 없이 피코 기본 내장 socket+ssl만 사용(requests 설치 금지). https는 인증서 검증 생략(CERT_NONE).
- 와이파이는 wifi_config.py 파일에 WIFI_SSID, WIFI_PASSWORD 두 변수로 저장해 두고 거기서 불러와.
- WS2813 LED 10개는 GP16에 연결, NeoPixel을 timing=(280,515,515,745)로 생성(없으면 색 깨짐), 밝기는 낮게(최대 60 정도).
- 응답이 크면 필요한 항목만 받아 메모리를 아끼고, 무한 루프엔 sleep으로 쉬어 줘.
강수확률 → LED 날씨 시계
[API] Open-Meteo(키 불필요): GET https://api.open-meteo.com/v1/forecast?latitude=LAT&longitude=LON&hourly=precipitation_probability&timezone=Asia%2FSeoul&forecast_days=1 → 응답 JSON의 hourly.precipitation_probability는 0~23시 24개 강수확률(%).
[만들 것] 오전 6시~밤 11시(18시간)를 LED 10칸에 고르게 나눠 각 시각 강수확률을 색으로 표시하는 ‘날씨 시계’. 맑음=초록·흐림=노랑·비가능=파랑·비확실=보라(임계값은 코드 위에서 조정), 10분마다 갱신.
[설정] LAT/LON은 코드 맨 위(서울 37.5665 / 126.9780).
현재 기온 → 무드등 색
[API] Open-Meteo(키 불필요): GET https://api.open-meteo.com/v1/forecast?latitude=LAT&longitude=LON&current=temperature_2m → 응답 JSON의 current.temperature_2m가 현재 기온(℃).
[만들 것] 현재 기온에 따라 LED 색이 바뀌는 무드등: 더우면(28℃ 이상) 빨강, 적당하면 초록, 추우면(10℃ 이하) 파랑. 10분마다 갱신.
[설정] LAT/LON은 코드 위.
