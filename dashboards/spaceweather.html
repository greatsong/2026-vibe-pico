📋 어떤 데이터인가요?

🐍 API 핵심 코드 — 복사해 내 프로젝트·AI에 응용

이 데이터를 받아오는 핵심만 추린 파이썬 코드예요(requests 사용). Streamlit 앱에 바로 쓰거나, 복사해서 AI(Claude 등)에게 “이 데이터로 ___ 만들어 줘”처럼 넘기면 됩니다.

📦 Streamlit Cloud에 배포한다면 requirements.txt에 requests를 한 줄 적어 주세요 (없으면 ModuleNotFoundError).

💻 파이썬 코드 보기 · 복사
우주날씨 (Kp 지수) · Python (requests)
import requests

# 우주날씨 Kp 지수 (지자기 교란·오로라 지표, 키 불필요)
rows = requests.get(
    "https://services.swpc.noaa.gov/products/noaa-planetary-k-index.json"
).json()

# 각 행은 딕셔너리: {"time_tag": .., "Kp": .., ...}
latest = rows[-1]
kp = float(latest["Kp"])        # 가장 최근 Kp 지수 (0~9)
when = latest["time_tag"]       # 측정 시각(3시간 간격)
print(when, kp)

🔧 공통 조건 — 아래 모든 프롬프트에 자동 포함 (펼쳐 보기)
공통 조건 · 피코·와이파이·LED
[공통 조건]
- 라즈베리파이 피코 2 W(MicroPython)에서 도는 완결형 main.py로 만들어 줘.
- 인터넷 접속은 외부 라이브러리 없이 피코 기본 내장 socket+ssl만 사용(requests 설치 금지). https는 인증서 검증 생략(CERT_NONE).
- 와이파이는 wifi_config.py 파일에 WIFI_SSID, WIFI_PASSWORD 두 변수로 저장해 두고 거기서 불러와.
- WS2813 LED 10개는 GP16에 연결, NeoPixel을 timing=(280,515,515,745)로 생성(없으면 색 깨짐), 밝기는 낮게(최대 60 정도).
- 응답이 크면 필요한 항목만 받아 메모리를 아끼고, 무한 루프엔 sleep으로 쉬어 줘.
Kp 지수 → 오로라 경보등
[API] NOAA SWPC(키 불필요): GET https://services.swpc.noaa.gov/products/noaa-planetary-k-index.json → 응답은 딕셔너리 배열. 마지막 항목의 "Kp" 값이 최신 Kp(0~9), "time_tag"가 측정 시각.
[만들 것] 최신 Kp를 LED로: 값이 클수록 칸을 많이 켜고, Kp 5 이상이면 보라색으로 깜빡(오로라 경보). 30분마다 갱신.
