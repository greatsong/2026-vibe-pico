화학🌐 국적 무관

📋 어떤 데이터인가요?

미국 국립보건원(NIH)이 운영하는 세계 최대 화학 백과 PubChem. 1억 종이 넘는 물질의 이름만 넣으면 분자식·분자량은 물론 구조 그림까지 그려 줍니다.

무엇물질 이름으로 분자식·분자량·구조 그림 (PubChem)
API 키필요 없음 · 무료
요청 예pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/caffeine/property/MolecularWeight/JSON
2D 그림같은 주소의 /PNG 로 평면 구조 이미지를 받습니다
3D 구조PubChem이 계산한 3D 입체구조 좌표(SDF, record_type=3d)를 받아 3Dmol.js로 회전 가능하게 그립니다 — 데이터는 PubChem이 제공
🔗 원 데이터 출처: PubChem (미국 국립보건원 NIH) ↗

🔧 공통 조건 — 아래 모든 프롬프트에 자동 포함 (펼쳐 보기)
공통 조건 · 피코·와이파이·LED
[공통 조건]
- 라즈베리파이 피코 2 W(MicroPython)에서 도는 완결형 main.py로 만들어 줘.
- 인터넷 접속은 외부 라이브러리 없이 피코 기본 내장 socket+ssl만 사용(requests 설치 금지). https는 인증서 검증 생략(CERT_NONE).
- 와이파이는 wifi_config.py 파일에 WIFI_SSID, WIFI_PASSWORD 두 변수로 저장해 두고 거기서 불러와.
- WS2813 LED 10개는 GP16에 연결, NeoPixel을 timing=(280,515,515,745)로 생성(없으면 색 깨짐), 밝기는 낮게(최대 60 정도).
- 응답이 크면 필요한 항목만 받아 메모리를 아끼고, 무한 루프엔 sleep으로 쉬어 줘.
분자량 비교 → LED 게이지
[API] PubChem(키 불필요): GET https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/NAME/property/MolecularWeight/JSON → 응답 JSON의 PropertyTable.Properties[0].MolecularWeight가 분자량.
[만들 것] 물질 이름 목록(예: water, glucose, caffeine)을 코드 위에 두고, 각 물질의 분자량을 차례로 LED 게이지로 보여 줘(0~400 → 0~10칸). 물질이 바뀔 때 색도 달리. (와이파이만 필요, 센서 없이 LED 출력)
[설정] 물질 이름 목록은 코드 위.
