CHAPTER 05

강수확률 물리 대시보드 (API×LED)

인터넷에서 오늘의 강수확률을 받아, 6시~23시를 10개 LED에 담는 ‘날씨 시계(물리 대시보드)’를 만들고, 같은 데이터를 보여 주는 웹 대시보드까지 완성합니다.

🎯 이 장을 마치면
  • Open-Meteo에서 강수확률 데이터를 받아올 수 있다
  • 받은 데이터(JSON)에서 시간대별 강수확률을 꺼낼 수 있다
  • 6시~23시의 강수확률을 10개 LED의 색으로 표현할 수 있다
  • LED와 똑같은 정보를 보여 주는 웹 대시보드(색 범례 포함)를 띄울 수 있다
💡 왜 배우나요?

앞에서는 센서로 내 주변을 봤어요. 이번엔 인터넷 너머 바깥 세상의 데이터를 다룹니다. 무료 날씨 API Open-Meteo에서 오늘의 강수확률을 받아, LED 바가 아침부터 밤까지 비 올 시간을 색으로 알려 주는 시계가 되고, 같은 데이터를 웹으로도 보여 줍니다. 나갈 때 LED만 보고 우산을 챙길 수 있죠.

핵심 개념

Open-Meteo
무료·API 키 불필요한 날씨 서비스. 위도·경도만 넣으면 시간대별 강수확률을 줍니다.
강수확률(precipitation_probability)
그 시각에 비가 올 가능성(%). 0시~23시까지 24개가 옵니다.
HTTP 요청 (requests)
피코가 인터넷 주소에 접속해 데이터를 받아오는 도구. requests.get(url)
6~23 → 10칸 매핑
오전 6시~밤 11시(18시간)를 10칸으로 고르게 나눠 대표 시각 10개를 LED에 배치합니다.

API는 ‘정해진 양식을 채워 보내면, 원하는 결과물을 정해진 형식으로 돌려주는 창구’예요. 아래 두 줄을 각각 클릭해 보세요 — 동사무소 등본 떼기와 피코의 날씨 받기가 똑같이 ‘요청 → 응답’으로 흐릅니다.

ℹ️ 먼저 — 와이파이 정보 파일 만들기 (wifi_config.py)

(피코는 2.4GHz 와이파이만 됩니다. 이름·비밀번호를 정확히.)
🔬 더 알아보기 — HTTPS와 인증서 — 코드의 CERT_NONE은 무슨 뜻일까?
주소가 https://로 시작하면, 피코와 서버 사이 통신이 암호화(TLS)됩니다. 중간에서 누가 엿봐도 내용을 못 읽죠.

원래 인터넷 브라우저는 ‘이 서버가 진짜 open-meteo가 맞는지’를 인증서로 확인합니다. 이때 신뢰할 수 있는 기관(CA) 목록이 필요한데, 피코에는 그 목록이 기본으로 들어 있지 않아요. 그래서 코드에서 ssl.CERT_NONE으로 ‘서버 신원 확인은 건너뛰고, 암호화만 쓰겠다’고 한 거예요.

교육용으로 공개 날씨 데이터를 받는 정도는 충분히 안전합니다. 다만 로그인·비밀번호처럼 민감한 정보를 주고받을 땐 신원 확인을 생략하면 안 되니, 그때는 인증서를 갖춘 환경에서 해야 합니다.

# 피코에 기본 내장된 socket + ssl 만으로 Open-Meteo(HTTPS)에 접속합니다.
import network, socket, ssl, json, time, gc
from wifi_config import WIFI_SSID as SSID, WIFI_PASSWORD as PASSWORD

LAT = 37.5665      # 위도 (우리 지역 좌표로 바꾸세요)
LON = 126.9780     # 경도
HOST = "api.open-meteo.com"


def connect_wifi():
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(SSID, PASSWORD)
    print("Wi-Fi 연결 중", end="")
    timeout = 20
    while not wlan.isconnected() and timeout > 0:
        print(".", end=""); time.sleep(0.5); timeout -= 1
    if wlan.isconnected():
        ip = wlan.ifconfig()[0]
        print("\n✅ 연결 완료!  IP:", ip)
        return ip
    print("\n❌ Wi-Fi 연결 실패")
    return None


def http_get_json(host, path):
    gc.collect()
    addr = socket.getaddrinfo(host, 443)[0][-1]
    s = socket.socket()
    s.connect(addr)
    try:
        ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
        ctx.verify_mode = ssl.CERT_NONE          # 피코엔 인증서 목록이 없어 검증 생략
        s = ctx.wrap_socket(s, server_hostname=host)
    except AttributeError:                       # 옛 펌웨어 호환
        s = ssl.wrap_socket(s, server_hostname=host)
    s.write(("GET %s HTTP/1.0\r\nHost: %s\r\nConnection: close\r\n\r\n"
             % (path, host)).encode())
    buf = b""
    while True:
        chunk = s.read(512)
        if not chunk:
            break
        buf += chunk
    s.close()
    body = buf.split(b"\r\n\r\n", 1)[1]          # 헤더 떼고 본문(JSON)만
    return json.loads(body)


if connect_wifi():
    path = ("/v1/forecast?latitude=%s&longitude=%s"
            "&hourly=precipitation_probability"
            "&timezone=Asia%%2FSeoul&forecast_days=1" % (LAT, LON))
    data = http_get_json(HOST, path)

    probs = data["hourly"]["precipitation_probability"]   # 24개 (0~23시)
    for hour in range(6, 24):
        print("%2d시 강수확률: %s%%" % (hour, probs[hour]))

def get_rain_probs():

def prob_to_color(p):
    if p is None:  return (0, 0, 0)
    if p < 20:     return (0, 30, 5)     # 맑음 - 연초록
    if p < 50:     return (30, 25, 0)    # 흐림 - 노랑
    if p < 80:     return (0, 10, 40)    # 비 가능 - 파랑
    return (15, 0, 40)                   # 비 확실 - 보라


def show(probs):
    for i, hour in enumerate(HOURS):

# 강수확률 단계 → LED 색(rgb). 웹 범례 색·의미와 똑같이 맞춰 둡니다.
#   0~20 맑음(연초록) · 20~50 흐림(노랑) · 50~80 비 가능(파랑) · 80~ 비 확실(보라)
LEVELS = [(20, (0, 30, 5)), (50, (30, 25, 0)), (80, (0, 10, 40)), (101, (15, 0, 40))]

def level_index(p):
    p = p if p is not None else 0
    for i, (thr, _rgb) in enumerate(LEVELS):
        if p < thr:
            return i
    return len(LEVELS) - 1

def http_get_json(host, path):
    gc.collect()
    addr = socket.getaddrinfo(host, 443)[0][-1]
    s = socket.socket()
    s.connect(addr)
    try:
        ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
        ctx.verify_mode = ssl.CERT_NONE          # 피코엔 인증서 목록이 없어 검증 생략
        s = ctx.wrap_socket(s, server_hostname=host)
    except AttributeError:                       # 옛 펌웨어 호환
        s = ssl.wrap_socket(s, server_hostname=host)
    s.write(("GET %s HTTP/1.0\r\nHost: %s\r\nConnection: close\r\n\r\n"
             % (path, host)).encode())
    buf = b""
    while True:
        chunk = s.read(512)
        if not chunk:
            break
        buf += chunk
    s.close()
    return json.loads(buf.split(b"\r\n\r\n", 1)[1])


def refresh():
    path = ("/v1/forecast?latitude=%s&longitude=%s"
            "&hourly=precipitation_probability"
            "&timezone=Asia%%2FSeoul&forecast_days=1" % (LAT, LON))
    hourly = http_get_json(HOST, path)["hourly"]
    state["probs"] = hourly["precipitation_probability"]   # 24개 (0~23시)
    state["date"] = hourly["time"][0][:10]                 # "YYYY-MM-DD"
    state["fetched"] = time.ticks_ms()
    for i, h in enumerate(HOURS):                          # LED 갱신
        np[i] = LEVELS[level_index(state["probs"][h])][1]
    np.write()
    print("날씨 갱신:", state["date"])


def refresh_if_due():
    if (state["fetched"] is None or
            time.ticks_diff(time.ticks_ms(), state["fetched"]) > REFRESH * 1000):
        try:
            refresh()
        except Exception as e:
            print("갱신 오류:", e)


def data_json():
    p = state["probs"]
    ago = 0 if state["fetched"] is None else \
        time.ticks_diff(time.ticks_ms(), state["fetched"]) // 1000
    leds = [{"h": h, "p": p[h], "lv": level_index(p[h])} for h in HOURS]
    hourly = [{"h": h, "p": p[h], "lv": level_index(p[h])} for h in range(6, 24)]
    return json.dumps({"date": state["date"], "ago": ago,
                       "leds": leds, "hourly": hourly})

def send_response(conn, status, content_type, body):
    header = ("HTTP/1.1 %s\r\nContent-Type: %s\r\nContent-Length: %d\r\n"
              "Access-Control-Allow-Origin: *\r\nConnection: close\r\n\r\n"
              % (status, content_type, len(body))).encode()
    conn.sendall(header + body)


def run_server():
    addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
    srv = socket.socket()
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind(addr)
    srv.listen(3)
    srv.settimeout(REFRESH)        # 방문자가 없어도 주기적으로 깨어나 날씨를 갱신
    print("대시보드 열림 — 위 주소로 접속하세요 (Ctrl+C로 종료)")
    while True:
        refresh_if_due()
        try:
            conn, _ = srv.accept()
        except OSError:            # accept 타임아웃 → 위로 올라가 날씨 갱신
            continue
        conn.settimeout(10)        # 받은 연결은 블로킹으로! (서버 타임아웃이 상속되면 요청을 못 읽어 페이지가 안 열림)
        try:
            req = conn.recv(512).decode("utf-8", "ignore")
            if "GET /data" in req:
                send_response(conn, "200 OK", "application/json", data_json().encode())
            else:
                send_response(conn, "200 OK", "text/html; charset=utf-8", HTML)
        except Exception as e:
            code = e.args[0] if e.args else None
            tip = {104: "브라우저가 연결을 먼저 끊음 (정상, 무시 OK)",
                   32:  "응답 도중 연결이 끊김 (정상)",
                   110: "응답 대기 시간 초과",
                   11:  "데이터가 아직 안 옴 (일시적)"}.get(code)
            print("요청 처리:", ("[%s] %s" % (code, tip)) if tip else ("오류 " + str(e)))
        finally:
            conn.close()

Open-Meteo 자세히 알기

Open-Meteo는 독일의 비영리 프로젝트로, 여러 나라 기상청의 공개 수치예보 모델을 모아 누구나 쓰도록 공개합니다. API 키도, 회원가입도 필요 없고, 비상업·교육용은 자유롭게 쓸 수 있어요. 주소(URL) 하나에 ‘어디(위도·경도)·무엇(변수)·언제(기간)’를 적어 보내면, 그 자리에서 JSON으로 답을 줍니다.

여러 종류의 API
forecast(예보) · archive(1940년~ 과거 데이터) · air-quality(대기질) · marine(파고·해양) · elevation(고도). 주소의 앞부분만 바꾸면 됩니다.
고를 수 있는 변수
기온 temperature_2m · 습도 relative_humidity_2m · 강수확률 precipitation_probability · 풍속 windspeed_10m · 기압 surface_pressure · 자외선 uv_index · 일사량 shortwave_radiation
응답(JSON) 구조
hourly.time(시각 배열)과 hourly.기온(값 배열)이 같은 순서로 짝을 이룹니다. 그래서 값[6]이 곧 그 날 6시 값이에요.
기간 고르기
forecast_days=1(오늘) · past_days=7(지난 일주일) · archive는 start_date/end_date로 특정 기간.
🔬 더 알아보기 — ‘강수확률 60%’가 실제로 뜻하는 것
강수확률(POP, Probability of Precipitation)은 그 시간·그 지역에 0.1mm 이상의 비가 내릴 통계적 확률입니다. 비의 ‘양’이나 ‘세기’가 아니라 ‘올지 안 올지의 가능성’이에요.

흔한 오해 두 가지:
· ‘60%’는 ‘하늘의 60%에 비가 온다’는 뜻이 아니에요.
· ‘비가 60% 세기로 온다’는 뜻도 아니에요.

예보 모델이 같은 조건을 여러 번 시뮬레이션했을 때 10번 중 6번꼴로 비가 내렸다는 의미에 가깝습니다. 그래서 강수확률이 높아도 실제로 안 올 수 있고, 낮아도 소나기가 올 수 있어요. 수업에서 ‘확률’과 ‘실제 관측’의 차이를 이야기하기 좋은 소재입니다.
💡 변수 바꾸는 법 — 주소의 hourly= 뒤만 고치면 끝
앞서 만든 코드에서 요청 주소의 hourly= 뒤만 바꾸면 다른 데이터를 받습니다.
· 기온: ...&hourly=temperature_2m
· 자외선 지수: ...&hourly=uv_index
· 일사량(태양광): ...&hourly=shortwave_radiation
여러 개를 쉼표로: ...&hourly=temperature_2m,relative_humidity_2m
과거 데이터는 주소를 https://archive-api.open-meteo.com/v1/archive 로 바꾸고 &start_date=2015-06-01&end_date=2015-06-30 처럼.

과학 수업에 쓸 만한 다른 오픈 API

Open-Meteo 말고도 무료에 대부분 키가 필요 없는 과학 데이터 API가 많아요 — 지진·ISS·일출몰·물질(화학)·생물 등. 과목별로 어떤 데이터를 주고 무엇을 탐구할 수 있는지를 부록 A에 한눈에 정리했고, 브라우저에서 바로 받아 그려 보는 라이브 대시보드(지도·그래프)로도 만들어 뒀습니다(국내 적용 여부도 표시). 키 없이 동작하는 것만 골랐고, 2026년 기준 응답을 확인했어요.

ℹ️ 피코로 가져올 때 한 가지
대부분 https + JSON이라, 이 장의 http_get_json()(소켓+ssl) 함수를 그대로 써서 받을 수 있어요. 다만 응답이 큰 API(지진 전체 목록, NASA 이미지 등)는 피코 메모리에 부담이 될 수 있으니, 필요한 항목만 요청하거나 수업에서는 컴퓨터(파이썬·브라우저)로 보여 주는 방법도 좋습니다.
