0️⃣ 먼저 읽기 — 점퍼 케이블, 3분이면 친해져요

키트 부품에는 그로브 커넥터가 없어서, 암수 점퍼 케이블로 쉴드의 번호 핀 소켓에 직접 연결합니다. 케이블 연결이 처음이라면 긴장될 수 있지만, 알아야 할 규칙은 딱 세 가지뿐이에요.

① 핀 소켓 두 줄이 정답지
쉴드에는 피코의 모든 핀이 GP 번호 그대로 암핀 소켓 두 줄로 나와 있어요. USB를 위로 두면 왼쪽 줄(GP0~GP15 쪽), 오른쪽 줄(GP16~GP28·3V3·GND 쪽). 위치가 헷갈리면 쉴드에 인쇄된 GP 번호를 읽으세요 — 그게 정답입니다.
② 암수 점퍼 꽂는 방향
수(뾰족한 핀) 쪽 → 쉴드의 소켓 구멍에, 암(구멍) 쪽 → 부품의 핀에 끼웁니다. 힘 주지 않아도 부드럽게 들어가요. 안 들어가면 방향이 반대인 거예요.
③ 색 약속
노랑 = 신호  흰색 = 둘째 신호
빨강 = 3V3(전원)  검정 = GND
전기적으로는 아무 색이나 동작하지만, 약속을 지키면 배선 점검이 5초로 끝나요.
🔑 GND와 3V3는 이렇게 찾아요
GND 구멍은 핀 줄 곳곳에 여러 개 있어서 아무거나 가까운 걸 쓰면 됩니다 — 각 프로젝트 배선도에 제일 가까운 GND를 표시해 뒀어요. 3V3는 오른쪽 줄 위쪽에 하나인데, 그보다 더 위에 있는 VBUS는 5V라서 절대 헷갈리면 안 돼요! 빨강 점퍼는 언제나 3V3.
⚠️ 연결 3계명 — 이것만 지키면 사고 없어요
① 꽂거나 뺄 때는 USB 케이블부터 뽑기  ② 켜기 전에 "빨강이 3V3, 검정이 GND"를 소리 내어 확인  ③ 헷갈리면 폰으로 배선 사진을 찍어 배선표와 대조. 신호선을 옆 칸에 잘못 꽂은 정도는 값이 이상하게 나올 뿐 대부분 괜찮지만, 3V3와 GND가 뒤바뀌면 부품이 상할 수 있으니 ②가 제일 중요합니다.
💡 그럼 그로브 소켓은 언제 쓰나요?
그로브 케이블이 소켓에 꽂히는 부품 전용이에요 — 우리 수업에선 LED 바(D16)와 MQ-2(A0 소켓, 그로브→암점퍼 변환 케이블) 둘뿐입니다. 키트 부품을 그로브 소켓에 꽂으려고 애쓰지 마세요. (그로브-점퍼 변환 케이블이 있다면 같은 GP핀이 나오는 소켓을 써도 코드는 동일하게 동작해요.)

점심시간이 끝난 5교시 교실, 창문은 닫혀 있고 공기는 점점 탁해지는데 아무도 눈치채지 못한 적 있지 않나요? 사람의 코는 서서히 나빠지는 공기에는 둔감해서, 정작 환기가 필요한 순간을 놓치기 쉽습니다. 이 프로젝트는 MQ-2 가스센서가 교실 공기를 쉬지 않고 감시하고, LED 바 10칸이 초록·노랑·빨강 신호등 게이지로 오염도를 한눈에 보여줍니다. 빨강 구간에 들어서는 순간 부저가 "삑삑" 두 번 울리면, 창가 자리 친구가 자연스럽게 창문을 여는 환기 담당이 되지요. 교탁 위에 올려두면 우리 반만의 공기 관제탑이 완성되고, 구글 시트 기록까지 붙이면 '우리 반 공기질의 하루' 데이터까지 손에 넣을 수 있습니다.

# 우리 반 공기 알리미 — 2단계 핵심 조합 확인용
from machine import Pin, ADC, PWM
from neopixel import NeoPixel
import time

mq2 = ADC(Pin(26))                                   # MQ-2 가스센서 (A0)
np = NeoPixel(Pin(16), 10, timing=(280, 515, 515, 745))  # timing 누락 시 색이 깨져요!
buzzer = PWM(Pin(18))
buzzer.duty_u16(0)                                   # 시작할 때 소리를 확실히 꺼 둡니다

LOW, HIGH = 20000, 50000   # 게이지 0칸~10칸 기준값 (교실에서 실측해 조정하세요)

def beep_twice():
    # 빨강 구간 진입을 알리는 '삑삑' 두 번
    for _ in range(2):
        buzzer.freq(880)
        buzzer.duty_u16(3000)
        time.sleep(0.15)
        buzzer.duty_u16(0)   # 다 쓰면 반드시 duty 0!
        time.sleep(0.1)

def show_gauge(level):
    # 켜진 칸 수만큼 초록(1~6) / 노랑(7~8) / 빨강(9~10)으로 표시해요
    for i in range(10):
        if i < level:
            if i < 6:
                np[i] = (0, 40, 0)
            elif i < 8:
                np[i] = (40, 30, 0)
            else:
                np[i] = (40, 0, 0)
        else:
            np[i] = (0, 0, 0)
    np.write()

alarmed = False   # 알람 상태 변수 — 빨강 구간에 '처음' 들어갈 때만 울리게 합니다

try:
    while True:
        try:
            raw = mq2.read_u16()
        except Exception:
            time.sleep(1)        # 센서 읽기 실패 시 이번 회차는 건너뜁니다
            continue

        # 원시값을 0~10칸으로 환산합니다
        level = (raw - LOW) * 10 // (HIGH - LOW)
        level = max(0, min(10, level))
        show_gauge(level)
        print("원시값:", raw, "/ 칸 수:", level, "/ 알람:", alarmed)

        if level >= 9 and not alarmed:
            beep_twice()         # 빨강 진입 순간에만 울립니다
            alarmed = True
        elif level <= 6:
            alarmed = False      # 초록까지 내려와야 다음 알람이 준비돼요 (히스테리시스)

        time.sleep(1)
finally:
    buzzer.duty_u16(0)           # Ctrl+C로 멈춰도 부저는 반드시 꺼 둡니다

# ── 확장 가이드의 미니 드라이버(i2c 설정 + lcd_init, lcd_print)를 이 위에 붙여넣으세요 ──
import network
import urequests
import time
from machine import Pin
from neopixel import NeoPixel
from wifi_config import SSID, PW

# LED 바 10칸 — timing을 빼먹으면 색이 깨져요!
np = NeoPixel(Pin(16), 10, timing=(280, 515, 515, 745))

# 와이파이에 연결합니다
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect(SSID, PW)
while not wlan.isconnected():
    print("와이파이 연결 중...")
    time.sleep(1)
print("연결 완료! IP:", wlan.ifconfig()[0])

lcd_init()  # LCD를 깨웁니다 (0x27/0x3F 주소는 드라이버가 자동 인식해요)

# 우리 학교 근처 좌표로 현재 기온 + 1시간 강수확률을 요청합니다
URL = ("https://api.open-meteo.com/v1/forecast"
       "?latitude=37.49&longitude=126.92"
       "&current=temperature_2m"
       "&hourly=precipitation_probability&forecast_hours=1")

def get_weather():
    r = urequests.get(URL)
    data = r.json()
    r.close()  # 메모리를 아끼려면 꼭 닫아 주세요
    temp = data["current"]["temperature_2m"]
    rain = data["hourly"]["precipitation_probability"][0]
    return rain, temp

def show_gauge(rain):
    lit = round(rain / 10)          # 강수확률 10%당 LED 1칸
    for i in range(10):
        if i < lit:
            # 50% 미만은 파랑(여유), 50% 이상은 빨강(우산!)
            np[i] = (0, 0, 40) if rain < 50 else (40, 0, 0)
        else:
            np[i] = (0, 0, 0)
    np.write()

while True:
    try:
        rain, temp = get_weather()
        show_gauge(rain)
        lcd_print("RAIN {:>3}%".format(int(rain)), 0)
        lcd_print("TEMP {:>5}C".format(temp), 1)
        print("강수확률", rain, "% / 기온", temp, "C")
    except Exception as e:
        print("데이터 읽기 실패:", e)   # 다음 주기에 다시 시도합니다
        try:
            lcd_print("API ERROR       ", 0)  # LCD에도 실패를 알려 줍니다
        except Exception:
            pass  # LCD 통신까지 안 되면 콘솔 안내만 남깁니다
    time.sleep(600)  # 10분마다 갱신 (테스트할 때는 10초로 줄여 보세요)

# 스터디룸 알리미 2단계 확인용 — PIR + 시간 로직 + LED 신호등
from machine import Pin
from neopixel import NeoPixel
import time

# WS2813은 timing을 꼭 지정해야 색이 깨지지 않아요
np = NeoPixel(Pin(16), 10, timing=(280, 515, 515, 745))
pir = Pin(20, Pin.IN)

EMPTY_AFTER = 30  # 마지막 감지 후 이만큼(초) 조용하면 '빈 방' (실전은 180 이상 추천)

def fill(r, g, b, n=10):
    # 앞에서부터 n칸만 켜고 나머지는 꺼요 (밝기는 40 이하!)
    for i in range(10):
        np[i] = (r, g, b) if i < n else (0, 0, 0)
    np.write()

# PIR는 전원 후 30초 워밍업이 필요해요 — 파란 게이지로 카운트다운!
print("PIR 워밍업 중... 30초만 기다려 주세요")
for sec in range(30, 0, -1):
    fill(0, 0, 30, (sec + 2) // 3)
    time.sleep(1)
print("워밍업 완료! 감지를 시작합니다")

last_motion = time.time()  # 마지막으로 움직임을 본 시각

while True:
    try:
        if pir.value() == 1:
            last_motion = time.time()  # 감지되면 시각 갱신!

        quiet = time.time() - last_motion  # 조용해진 지 몇 초?

        if quiet < EMPTY_AFTER:
            # 사용 중: 빨강. 조용할수록 칸이 줄어 '곧 비워질 예감'까지 보여줘요
            remain = EMPTY_AFTER - quiet
            n = max(1, min(10, remain * 10 // EMPTY_AFTER + 1))
            fill(40, 0, 0, n)
            print("사용 중 | 마지막 감지", quiet, "초 전")
        else:
            fill(0, 40, 0)  # 비어 있음: 초록 10칸
            print("비어 있음 |", quiet, "초째 조용")
    except Exception as e:
        print("오류 발생, 계속 진행:", e)

    time.sleep(0.5)

from machine import Pin, time_pulse_us
import neopixel
import time

# 내 수거함에 맞게 두 값을 꼭 조정하세요!
EMPTY_CM = 40.0  # 빈 통: 센서에서 바닥까지 거리(cm)
FULL_CM = 5.0    # 가득: 쓰레기 표면까지 최소 거리(cm)

trig = Pin(18, Pin.OUT)
echo = Pin(19, Pin.IN)
np = neopixel.NeoPixel(Pin(16), 10, timing=(280, 515, 515, 745))

def measure_once():
    # 10us 트리거 펄스 → 에코 왕복 시간 → 거리 환산
    trig.value(0); time.sleep_us(2)
    trig.value(1); time.sleep_us(10)
    trig.value(0)
    us = time_pulse_us(echo, 1, 30000)  # 30ms 넘으면 음수 반환
    if us < 0:
        return None
    return us * 0.0343 / 2  # 음속 343m/s, 왕복이라 2로 나눠요

def measure_median(n=5):
    # 5회 재서 중앙값 사용 — 튀는 값에 훨씬 강합니다
    vals = []
    for _ in range(n):
        try:
            d = measure_once()
            if d is not None:
                vals.append(d)
        except Exception:
            pass
        time.sleep_ms(60)
    if not vals:
        return None
    vals.sort()
    return vals[len(vals) // 2]

def show_gauge(pct):
    lit = round(pct / 10)  # 10%당 1칸
    for i in range(10):
        if i < lit:
            if pct >= 80:
                np[i] = (40, 0, 0)    # 빨강: 비울 때!
            elif pct >= 50:
                np[i] = (40, 20, 0)   # 주황: 슬슬 주의
            else:
                np[i] = (0, 40, 0)    # 초록: 여유
        else:
            np[i] = (0, 0, 0)
    np.write()

while True:
    d = measure_median()
    if d is None:
        print("측정 실패 — TRIG/ECHO 배선을 확인하세요")
    else:
        pct = (EMPTY_CM - d) / (EMPTY_CM - FULL_CM) * 100
        pct = max(0, min(100, pct))
        print("거리 {:.1f}cm -> 채움 {:.0f}%".format(d, pct))
        show_gauge(pct)
    time.sleep(1)

확인용 코드 — 리모콘 1·2번을 누를 때마다 LED 막대가 빨강/파랑 두 진영으로 갈리면 성공MicroPython
# 2단계 확인용 — IR 리모콘 투표 + LED 실시간 막대그래프
from machine import Pin, time_pulse_us
from neopixel import NeoPixel
import time

ir = Pin(1, Pin.IN)  # IR 수신기 (핀 소켓 GP1)
np = NeoPixel(Pin(16), 10, timing=(280, 515, 515, 745))  # timing 빼면 색 깨져요!

BTN_A = 0x45  # 1번 버튼 코드 (1단계에서 출력된 내 리모콘 값으로 바꾸세요)
BTN_B = 0x46  # 2번 버튼 코드

votes_a, votes_b = 0, 0
last_vote = 0  # 연타 방지용 마지막 투표 시각

def read_nec():
    """NEC 적외선 신호 32비트를 해석해 명령 코드를 돌려줍니다."""
    try:
        if time_pulse_us(ir, 0, 100000) < 8000:  # 9ms 리드 펄스 확인
            return None
        if time_pulse_us(ir, 1, 6000) < 4000:    # 4.5ms 공백 (반복 코드는 여기서 걸러져요)
            return None
        data = 0
        for _ in range(32):  # 공백 길이가 길면 1, 짧으면 0
            if time_pulse_us(ir, 0, 2000) < 0:
                return None
            space = time_pulse_us(ir, 1, 3000)
            if space < 0:
                return None
            data = (data >> 1) | (0x80000000 if space > 1000 else 0)
        cmd = (data >> 16) & 0xFF   # 명령 바이트
        inv = (data >> 24) & 0xFF   # 반전 바이트 (오류 검증용)
        return cmd if (cmd ^ inv) == 0xFF else None
    except OSError:
        return None

def show_bar():
    """득표 비율만큼 왼쪽은 빨강(A안), 오른쪽은 파랑(B안)으로 채웁니다."""
    total = votes_a + votes_b
    np.fill((0, 0, 0))
    if total > 0:
        n_a = round(votes_a / total * 10)
        for i in range(10):
            np[i] = (30, 0, 0) if i < n_a else (0, 0, 30)
    np.write()

print("투표 시작! 리모콘 1번=A안, 2번=B안")
while True:
    cmd = read_nec()
    if cmd is None:
        continue
    now = time.ticks_ms()
    if time.ticks_diff(now, last_vote) < 800:  # 0.8초 안 연타는 무효표!
        continue
    if cmd == BTN_A:
        votes_a += 1
    elif cmd == BTN_B:
        votes_b += 1
    else:
        continue  # 1·2번 외 버튼은 무시해요
    last_vote = now
    print("현재 득표 → A안:", votes_a, "/ B안:", votes_b)
    show_bar()
